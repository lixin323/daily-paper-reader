## 摘要
视觉-语言-动作（VLA）模型为通用机器人策略提供了一种有前景的范式，但其适应性受到数据效率低下和泛化能力差的阻碍。我们认为这些瓶颈源于主流的直接指令到控制映射（Direct Instruction-to-Control Mapping），该方法迫使模型记忆整体轨迹而非可复用的运动模式（即基元）。我们提出PrimitiveVLA，一个将范式转向以基元为中心的“拆解与组装”范式的新框架。在共享的多模态规范表示（MCR）支持下，PrimitiveVLA统一了两个阶段：（1）微调阶段拆解（Disassembly），使用自动化流水线将演示拆解为可复用的基元；（2）推理阶段组装（Assembly），采用基于VLM的规划器和LLM生成的切换模块实现鲁棒的闭环执行。通过将任务拆解为可复用的基元，PrimitiveVLA使VLA模型能够学习不变的运动模式而不是特定任务的轨迹。大量实验表明，我们的框架提高了数据效率，并在未见过的和长程任务中实现了优越的零样本泛化。

## Abstract
Vision-Language-Action (VLA) models offer a promising paradigm for generalist robotic policies, yet their adaptation is hindered by data inefficiency and poor generalization. We argue that these bottlenecks stem from the prevailing Direct Instruction-to-Control Mapping, which forces models to memorize monolithic trajectories rather than reusable motion patterns, i.e., primitives. We propose PrimitiveVLA, a framework that shifts this paradigm toward a Primitive-Centric Disassemble & Assemble paradigm. Supported by a shared Multimodal Canonical Representation (MCR), PrimitiveVLA unifies two phases: (1) Fine-tuning-phase Disassembly, which uses an automated pipeline to disassemble demonstrations into reusable primitives; and (2) Inference-phase Assembly, which employs a VLM-based planner and an LLM-generated switch module for robust closed-loop execution. By disassembling tasks into reusable primitives, PrimitiveVLA enables VLA models to learn invariant motion patterns instead of task-specific trajectories. Extensive experiments show that our framework improves data efficiency and achieves superior zero-shot generalization across unseen and long-horizon tasks.

- **核心问题**：当前主流视觉-语言-动作（VLA）模型（如OpenVLA、π0系列）采用**直接指令到控制映射**（Direct Instruction-to-Control Mapping）范式，将任务级指令直接映射到低层动作轨迹。这种范式迫使模型记忆完整的、特定场景的轨迹，而非可复用的运动模式，导致**数据效率低**（同一动作模式在不同任务中需独立学习）和**跨任务泛化差**（对未见过的物体-技能组合几乎失效）。
- **动机**：作者指出，这一瓶颈不仅源于数据规模，更源于缺乏对物理运动模式与上下文的解耦。若能先将任务拆解为任务无关的**运动基元**（如抓取、放置、推拉等），再让模型学习这些基元，则可将无限任务泛化问题转化为有限基元的组合，从而大幅提升效率和泛化能力。

### 2. 方法论：核心思想、关键技术细节、算法流程
- **核心思想**：提出**基元中心的“拆解与组装”范式**（Primitive-Centric Disassemble & Assemble）。微调阶段将演示轨迹自动拆解为可复用的运动基元；推理阶段将基元按规划序列组装执行新任务。
- **关键技术**：
  - **11个预定义运动基元库**：分为空间搬运（Grasp, Place, Lift, Move）、接触交互（Push, Pull, Insert, Press）、姿态调整（Twist, Tilt, Rotate）三类。
  - **微调阶段拆解**：
    - **基元序列推理**：用VLM（Qwen3-VL）分析任务指令和视频帧，生成基元顺序。
    - **状态边界分割**：用LLM（DeepSeek-V3）为每个基元生成Python终止条件代码（如Grasp：夹爪闭合且高度上升），在局部窗口内检测物理状态变化，实现精确分割。
  - **推理阶段组装**：
    - **VLM规划器**：通过检索相似任务的基元序列（从拆解库中）作为上下文，为新任务规划基元顺序。
    - **LLM开关模块**：根据基元定义和分割代码，生成轻量级Python函数，基于历史滑动窗口的统计趋势判断切换时机，实现闭环执行。
  - **多模态规范表示（MCR）**：统一不同任务的输入，消除上下文干扰：
    - **语义统一**：将原指令映射为标准基元指令（如“抓住绿色掩码物体”），迫使模型学习模式而非文本变体。
    - **视觉兼容**：使用SAM+Cutie跟踪物体生成掩码，作为视觉输入的一部分，保留任务上下文但格式一致。
- **算法流程**：
  - 微调：轨迹 → VLM基元序列 + LLM分割代码 → 分割出基元样本 → MCR转换 → 训练VLA（优化Lprim）。
  - 推理：新任务 → 检索拆解库 → VLM规划器生成基元序列 → 实时执行：MCR处理当前观测 + VLA输出动作 + LLM开关监控历史窗口 → 切换基元。

### 7. 优点
- **范式创新**：从“记忆轨迹”转变为“学习可复用运动模式”，直接解决数据低效和泛化瓶颈。
- **自动化与无需手动标注**：VLM+LLM自动完成拆解，无需人工标注基元标签。
- **模型无关**：成功应用于三种主流VLA架构（Transformer、优化调参、流匹配），通用性强。
- **低推理开销**：规划与开关代码在预执行阶段完成，运行时仅增加毫秒级延迟。
- **可解释性**：基元序列和开关逻辑具有语义和物理可理解性。

### 8. 不足与局限
- **基元集预定义**：当前11个基元基于标准夹具操作，未涵盖灵巧手或特殊工具的高自由度操作。论文承认这一局限，并指出未来可探索无监督基元发现。
- **依赖VLM/LLM的噪声**：虽然实验表明VLM/LLM的错误（<5%~10%）被后续规则或VLA鲁棒性吸收，但在极端不熟悉场景下（如RLBench的高变度）可能导致分割偏差。
- **长程任务仍依赖手动定义切换逻辑**：虽然生成过程自动化，但物理阈值和窗口大小仍由LLM根据语义定义推导，在高度动态环境中可能需校准。
- **未报告统计显著性**：虽然给出了数值对比，但未提供置信区间或方差分析，对随机性影响讨论不足。
- **实际部署限制**：真实世界的掩码跟踪依赖Cutie，在光照突变或严重遮挡时可能漂移；文中未专门测试这种极端情况。
