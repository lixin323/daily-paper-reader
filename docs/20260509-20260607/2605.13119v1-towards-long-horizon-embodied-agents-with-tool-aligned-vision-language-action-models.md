## 摘要
视觉-语言-动作（VLA）模型是有效的机器人动作执行器，但由于扩展的闭环规划和多样化的物理操作双重负担，它们在长时域任务上仍然受限。因此，我们提出了VLAs-as-Tools策略，将这一负担分配给一个用于时间推理的高层视觉语言模型（VLM）智能体和一组用于多样化本地物理操作的专用VLA工具。VLM负责场景分析、全局规划和恢复，而每个VLA工具执行一个有限子任务。为了在长时域任务中紧密耦合智能体规划与VLA工具执行，我们引入了VLA工具族接口，该接口提供显式的工具选择和执行中进度反馈，使得无需连续轮询智能体即可进行高效的事件触发式智能体重规划。为了获得能够忠实遵循智能体调用的多样化专用VLA工具，我们进一步提出了工具对齐后训练（TAPT），它构建了用于指令遵循的调用对齐训练单元，并采用工具族残差适配器进行高效的工具专业化。实验表明，VLAs-as-Tools在LIBERO-Long上将π_{0.5}的成功率提高了4.8个百分点，在RoboTwin上提高了23.1个百分点，并通过非偏置率衡量的调用保真度进一步提升了15.0个百分点。代码将开源。

## Abstract
Vision-language-action (VLA) models are effective robot action executors, but they remain limited on long-horizon tasks due to the dual burden of extended closed-loop planning and diverse physical operations. We therefore propose VLAs-as-Tools, a strategy that distributes this burden across a high-level vision language model (VLM) agent for temporal reasoning and a family of specialized VLA tools for diverse local physical operations. The VLM handles scene analysis, global planning, and recovery, while each VLA tool executes a bounded subtask. To tightly couple agent planning with VLA tool execution in long-horizon tasks, we introduce a VLA tool-family interface that exposes explicit tool selection and in-execution progress feedback, enabling efficient event-triggered agent replanning without continuous agent polling. To obtain diverse specialized VLA tools that faithfully follow agent invocations, we further propose Tool-Aligned Post-Training (TAPT), which constructs invocation-aligned training units for instruction following and adopts tool-family residual adapters for efficient tool specialization. Experiments show that VLAs-as-Tools improves the success rate of $π_{0.5}$ by 4.8 points on LIBERO-Long and 23.1 points on RoboTwin, and further enhances invocation fidelity by 15.0 points as measured by Non-biased Rate. ## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：现有视觉-语言-动作（VLA）模型在长时域（long-horizon）具身任务中表现受限，主要原因在于它们需要同时承担**扩展的闭环规划**和**多样化的物理操作**双重负担。单独使用端到端VLA作为长时域智能体时，规划能力弱、易受演示分布偏置影响、失败恢复困难。
- **背景**：已有两条路线：① 在端到端VLA内部引入语义子任务预测（如π₀.₅）；② 采用智能体式（agentic）架构，由高容量LLM进行规划并调用低层技能或API（如SayCan、Code as Policies）。前者物理执行强但长时域推理弱，后者规划强但物理工具弱（通常是手工设计的技能）。二者存在互补性鸿沟。
- **核心思路**：提出 **VLAs-as-Tools** 策略，将VLA模型作为可调用的、有限范围的物理工具，由高层VLM智能体负责全局规划、状态追踪、错误恢复，多个专用VLA工具分别执行有限子任务，从而将长时域负担解耦到不同模块上。

## 2. 方法论：核心思想与关键技术细节
### 整体框架
- **高层VLM智能体（Πϕ）**：接收用户目标q，维护智能体状态sk，在决策步骤k输出调用消息ck = (gk, zk)，其中gk为工具族标签（如grasp, open, place），zk为场景级子任务指令。
- **VLA工具族（T = {Tg}g∈G）**：每个Tg是一个专门化的VLA执行器，处理有限时间窗口内的动作生成。执行过程中返回进度反馈信号pt ∈ [0,1]。
- **VLA工具族接口**：定义双向消息集C（调用消息）和R（反馈消息），支持显式工具选择和执行中进度反馈，实现事件触发的智能体重新规划，无需连续轮询。

### 工具对齐后训练（TAPT）
- **调用对齐训练单元**：将演示轨迹分割为有限窗口，每个窗口标注调用c=(g,z)，包含观测、动作、进度目标。RL阶段也以调用为单位：从子任务起始状态开始rollout，由局部完成谓词ψz,g给出稀疏奖励（完成则奖励1，否则0）。

- **训练目标**：联合动作克隆损失和进度预测损失（L2范数），RL阶段使用GRPO优化调用级完成奖励。

- **反馈消息R**：连续进度信号pt，由附加的进度预测头ψω(bt)输出，受阈值监控决定是否重规划。
