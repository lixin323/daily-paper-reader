## 摘要
具身智能通常通过针对特定任务（如操作或导航）的专用模型进行研究，导致能力碎片化且泛化能力有限。在本工作中，我们研究是否可以将异构的具身决策问题统一到一个单一的视觉-语言-动作模型中。我们提出Qwen-VLA，一个统一的具身基础模型，它通过基于DiT的动作解码器，将Qwen的视觉-语言建模栈从感知、理解和推理扩展到连续动作和轨迹生成。Qwen-VLA通过大规模联合预训练策略在多样数据源上进行训练，包括机器人操作轨迹、人类自我中心演示、合成模拟数据、视觉-语言导航数据、轨迹中心监督以及辅助的视觉-语言数据。为支持多种机器人平台，我们引入具身感知提示条件化，其中机器人特定的文本描述指定当前具身和控制惯例。我们进一步将操作、导航和轨迹预测统一到一个动作与轨迹预测框架中，实现了跨机器人形态、任务系列和环境的可迁移视觉定位、空间推理和连续动作生成。在操作、导航和轨迹中心基准上的实验显示了在多任务性能以及场景布局、背景、光照、物体配置和机器人具身变化下的分布外泛化方面的一致性。Qwen-VLA-Instruct在LIBERO上达到97.9%，在Simpler-WidowX上达到73.7%，在RoboTwin-Easy/Hard上达到86.1%/87.2%，在R2R上达到69.0% OSR，在RxR上达到59.6% SR，在真实世界ALOHA实验中平均OOD成功率为76.9%，在DOMINO动态操作中零样本成功率达26.6%。

## Abstract
Embodied intelligence is often studied through specialized models for individual tasks such as manipulation or navigation, resulting in fragmented capabilities and limited generalization across tasks, environments, and robot embodiments. In this work, we study whether heterogeneous embodied decision-making problems can be unified within a single vision-language-action model. We present Qwen-VLA, a unified embodied foundation model that extends Qwen's vision-language modeling stack from perception, understanding, and reasoning to continuous action and trajectory generation through a DiT-based action decoder. Qwen-VLA is trained with a large-scale joint pretraining recipe over diverse data sources, including robotics manipulation trajectories, human egocentric demonstrations, synthetic simulation data, vision-and-language navigation data, trajectory-centric supervision, and auxiliary vision-language data. To support multiple robot platforms, we introduce embodiment-aware prompt conditioning, where robot-specific textual descriptions specify the current embodiment and control convention. We further cast manipulation, navigation, and trajectory prediction into a unified action-and-trajectory prediction framework, enabling transferable visual grounding, spatial reasoning, and continuous action generation across robot morphologies, task families, and environments. Experiments on manipulation, navigation, and trajectory-centric benchmarks show consistent multi-task performance and out-of-distribution generalization under variations in scene layout, background, lighting, object configuration, and robot embodiment. Qwen-VLA-Instruct achieves 97.9% on LIBERO, 73.7% on Simpler-WidowX, 86.1%/87.2% on RoboTwin-Easy/Hard, 69.0% OSR on R2R, 59.6% SR on RxR, 76.9% average OOD success in real-world ALOHA experiments, and 26.6% zero-shot success on DOMINO dynamic manipulation.

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想

- 将操作、导航、人类自我中心动作建模统一在 **共享的动作与轨迹预测空间** 中，采用联合条件预测框架：给定视觉上下文 \(o_t\)、语言指令 \(x\)、具身描述 \(e\)（文本提示）和可选任务标识 \(z\)，预测目标序列 \(y_{t:t+H-1}\)。
- 使用 **流匹配（Flow Matching）** 目标训练 DiT 动作解码器，实现连续高维动作生成。

### 2.2 模型架构

- **视觉-语言骨干网络**：采用 Qwen3.5-4B，原生多模态模型，视觉与文本令牌早期融合，支持图像、视频和语言统一处理。混合注意力设计（门控线性注意力 + 分组查询 Softmax 注意力）。
- **动作专家**：单流 DiT 风格流匹配策略，包含约 1.15B 参数（16 个 DiT 块，每块 70.8M）。将 VLM 隐藏状态与噪声动作块拼接，通过联合自注意力 + AdaLN 时间步条件 + 多段 RoPE 处理。训练目标为条件流匹配损失 \(L_{act}\)，使用 Euler 积分进行推理。

### 2.3 具身感知提示条件化（Embodiment-aware Prompt Conditioning）

- 每个训练样本前置机器人特定文本提示，模板如：
  “The robot is {robot_tag} with {single arm / dual arms}[, waist][, and mobile base]. The control frequency is {FPS} Hz. Please predict the next {chunk_size} control actions to execute the following task: {ori_instruction}.”
- 提示指定机器人平台、控制频率、预测步数等，是模型获取具身特定控制语义的唯一接口。

### 2.4 统一动作与轨迹表示

- 目标张量形状为 \( \mathbb{R}^{H \times K} \)，H 为固定预测地平线，K 为通道数。
- **控制信号类型**：操作信号（delta 末端位置、欧拉角/四元数、关节位置、夹爪开度、灵巧手关节）、导航信号（\((\Delta x, \Delta y, \Delta \theta)\)）。
- **通道布局**：有效通道置于前 c 维，其余零填充；使用二值掩码 M 指示有效通道和时间步。
- **任务感知条件化**：提示令牌由 VLM 处理后与噪声动作块拼接输入 DiT。

### 2.5 训练目标

- **流匹配动作损失**：条件流匹配，双重平均避免填充通道主导梯度。
- **视觉-语言损失**：标准下一个令牌预测损失，保持骨干网络能力。
- **联合损失**：\(L = \lambda_{act} L_{act} + \lambda_{vl} L_{vl}\)。

### 2.6 四阶段训练流程

1. **Stage I: 文本到动作 DiT 预训练（T2A）**：冻结 VLM，只训练 DiT，仅基于文本和具身提示（不含图像）学习语言到动作的解压缩。使用 Sigmoid-Normal 时间步分布。
2. **Stage II: 持续预训练（CPT）**：解冻两个模块，在异构数据上联合训练，使动作先验与视觉观察结合。
3. **Stage III: 有监督微调（SFT）**：从 CPT 检查点分两支：多任务 SFT（异构任务联合）和真实机器人部署 SFT（自采遥操作数据）。使用 Beta 时间步分布。
4. **Stage IV: 强化学习（RL）**：从 SFT 检查点出发，在 SimplerEnv 中基于稀疏成功奖励进行 PPO 优化（GAE），产生最终模型 Qwen-VLA-Instruct。采用分离评论家头、概率流 ODE 转 SDE 计算重要性比率。

## 6. 论文的主要结论与发现

1. **单一通用模型可在多个异构具身任务上超越大多数专用模型**：Qwen-VLA-Instruct 在 LIBERO（97.9%）、Simpler-WidowX（73.7%）、RoboTwin（86.1%/87.2%）、RoboCasa-GR1（56.7%）上优于或持平最佳专用模型。
2. **大规模异构预训练带来显著泛化能力**：T2A 阶段将成功率从 60.9% 提升至 71.1%（+10.2pp）；CPT 基础模型 Qwen-VLA-Base 已具备合理性能（LIBERO 90.8%）。
3. **SFT+RL 后训练带来一致提升**：RL 在 SimplerEnv 训练后，不仅提升该环境（+2.9pp），还对未见环境有轻度正迁移（RoboCasa +0.7pp，DOMINO SR +0.9pp）。
4. **具身感知提示可有效统一多样机器人平台**：无需每个形态独立训练，仅靠文本提示即可适配不同控制空间。
5. **视觉-语言辅助数据对操作学习有益**：在需要细粒度物体识别和组合指令解析的基准（RoboCasa-GR1 +4.9%，RoboTwin +4.6%）上增益明显。
6. **合成数据多样性对先验形成至关重要**：纯真实数据 T2A 仅 51.0%，纯合成 64.1%，混合约 20% 合成 + 80% 真实达到最佳 71.1%。
7. **零样本迁移到动态操作**：未使用任何动态训练数据，DOMINO SR 26.6% 超过所有微调方法，归因于统一预训练获得的可迁移基元。

## 7. 优点：方法或实验设计上的亮点

- **统一框架设计优雅**：将异构任务归结为单一条件预测框架，通过文本提示区分具身，无需修改架构，具有较强的扩展性。
- **四阶段训练策略合理有效**：T2A 阶段从压缩视角出发，先建立语言-动作先验再视觉接地，稳定且高效；消融证实每一步的必要性。
- **大规模多源预训练**：涵盖真实机器人、仿真、自我中心人类数据、导航、自动驾驶 VQA 等，数据量级大（数万小时），覆盖面广。
- **全面的 OOD 评估**：从颜色、实例、位置、背景、指令到动态操作、跨机器人形态，系统测试泛化能力。
- **消融分析扎实**：对 T2A 的数据组成、预测模式、时间步分布、训练时长、投影设计、状态条件化等进行细致比较，结论可靠。
- **真实世界验证**：在 ALOHA 平台上进行了域内和多种 OOD 实验，且设置与仿真中一致，增强了结论的可信度。
- **代码和模型开源**：文末给出 GitHub 链接，可复现。

## 8. 不足与局限

- **具身动作数据仍相对稀缺**：与视觉-语言预训练数据相比，机器人数据规模小、多样性有限，限制了长尾物体、环境和交互的鲁棒性。
- **联合训练引入优化权衡**：行动导向训练对纯视觉-语言和导航任务有一定回归（论文提到未量化具体幅度），需要更好的目标平衡或数据课程。
- **评估仍以短地平线、基准驱动为主**：真实世界仅在 ALOHA 单个平台进行短期任务评估，缺少长时间、复杂、失败可恢复的部署测试。
- **状态条件化收益有限**：实验表明增加关节状态仅带来 0.7-1.3pp 提升，但未系统评估在无视觉反馈场景或高精度任务中的必要性。
- **算力细节未披露**：未报告 GPU 型号、数量、训练总时长，不利于其他团队复现或估计资源成本。
- **RL 仅在一个仿真环境（SimplerEnv）中进行**：虽然观察到正迁移，但更广泛的多环境 RL 训练可能带来更大提升。论文承认其局限性。
