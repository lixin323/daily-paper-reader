## 摘要
运动想象（MI）脑-机接口（BCI）已成为建立人脑与外部设备之间灵活通信途径的一种有前景的方法，尤其适用于受中风或神经退行性疾病影响的个体。由于脑电图（EEG）记录包含大量噪声，且与潜在大脑活动之间呈现复杂、弱信息性的关系，运动想象脑电图（MI-EEG）的可靠解码仍具挑战性。尽管深度学习为直接从EEG信号中学习表征提供了有效手段，但其在MI-EEG特征学习中的应用仍相对有限。本研究引入了一种混合深度学习架构，该架构将卷积神经网络（CNN）与双向长短期记忆（bi-LSTM）网络相结合。CNN用于直接从原始MI-EEG记录中学习高级空间和时间表征，而bi-LSTM则对提取特征间的时间依赖和关系进行建模。所提出的方法使用公开数据集和通过EEG采集系统获取的私有数据集进行评估。实验结果表明，CNN&bi-LSTM架构在二分类和三分类运动想象分类中均提供了稳健的性能，并在所评估的方法中展现出有前景的跨受试者解码能力。

## Abstract
Motor imagery (MI) brain--computer interfaces (BCIs) have emerged as a promising approach for establishing flexible communication pathways between the human brain and external devices , particularly for individuals affected by stroke or neurodegenerative disorders. Reliable decoding of motor-imagery electroencephalography (MI-EEG) remains challenging because EEG recordings contain substantial noise and exhibit complex, weakly informative relationships with the underlying brain activity. Although deep learning provides an effective means of learning representations directly from EEG signals, its application to MI-EEG feature learning remains comparatively limited. This study introduces a hybrid deep-learning architecture that integrates a convolutional neural network (CNN) with a bidirectional long short-term memory (bi-LSTM) network. The CNN is used to learn high-level spatial and temporal representations directly from raw MI-EEG recordings, whereas the bi-LSTM models temporal dependencies and relationships among the extracted features. The proposed approach is evaluated using both a publicly available dataset and a privately acquired dataset obtained with an EEG acquisition system. The experimental results indicate that the CNN\&bi-LSTM architecture provides robust performance for both two- and three-class motor-imagery classification and demonstrates promising subject-independent decoding capability across the evaluated methods.

  - 传统机器学习方法（LDA、SVM、Naive Bayes）在非线性、高噪声、强相关的EEG数据上性能有限，且严重依赖人工特征工程。
  - 单纯基于CNN或RNN的深度学习方法仍需大量的模型调参和手工特征设计，未能充分利用EEG中长程时间依赖与空间结构信息。
- **研究意义**：本文提出一种将CNN与双向LSTM结合的混合深度学习架构，直接从原始EEG信号中学习空间和时间表征，为MI-EEG解码提供了一种数据驱动、端到端的解决方案。

## 2. 方法论：核心思想与技术细节

### 2.1 整体框架

采用“预处理 → CNN空间特征提取 → 批归一化 → bi-LSTM时间依赖建模 → 分类”的流水线架构，实现从原始EEG信号到运动意图类别的端到端学习。

### 2.2 数据预处理

1. **参考电极设置**：以Cz（顶点电极）作为参考电极，通过公式 `Cz(Vm) = (I − VCz)Vm` 对原始信号进行重参考。
2. **电极选择**：选用P3、P4、C3、C4、O1、O2、Pz、Fz、Cz等MI-EEG主要电极位置。
3. **噪声去除**：采用小波去噪方法去除信号中的干扰成分。
4. **信号滤波**：保留8–23 Hz频段，覆盖μ节律和β节律的主要频率成分。

### 2.3 CNN特征提取

- 使用8个空间滤波器，卷积核尺寸为 `[36 × 1]`，每个特征图尺寸为 `(1 × 60)`。
- 卷积后通过非线性激活函数，生成高层空间特征表征；公式：`O²ₘ = f(Σᵢⱼ Xᵢ,ⱼ × k²ₘ + b²ₘ)`。
- 空间卷积层本质上是**可学习的空间滤波操作**，能够自适应地从训练数据中获得类似带通滤波和能量提取的信号变换。

### 2.4 批归一化（BN）

- 对每个特征维度进行零均值、单位方差归一化：`BN(Xᵢ) = (Xᵢ − E[Xᵢ]) / √Var[Xᵢ]`。
- 目的：加速优化、改善泛化、降低对初始化和学习率的敏感性。

### 2.5 双向LSTM

- **bi-LSTM结构**：正向层和反向层同时处理序列，输出由两层共同决定：`yₜ = υ(Wₕᵧ hᶠₜ + Wₖᵧ hᵇₜ + bᵧ)`。
- **LSTM单元**：包含输入门、遗忘门、输出门和记忆细胞，核心更新公式包括：
  - 遗忘门：`zₜ = σ(W_f xₜ + U_f hₜ₋₁ + b_f)`
  - 输入门：`iₜ = σ(W_i xₜ + U_i hₜ₋₁ + b_i)`
  - 输出门：`oₜ = σ(W_o xₜ + U_o hₜ₋₁ + b_o)`
  - 细胞状态：`cₜ = zₜ ⊙ cₜ₋₁ + iₜ ⊙ σ(W_c xₜ + U_c cₜ₋₁ + b_c)`
  - 隐藏状态：`hᶠₜ = oₜ ⊙ tanh(cₜ)`
- **设计意图**：双向处理使网络能同时利用过去和未来的上下文信息，更全面地建模EEG中运动想象相关的时间动态。
- **初始化策略**：使用LASSO获得的系数初始化权重矩阵W，使隐藏单元从最小二乘回归的可行解出发，再进行优化。
- **损失函数**：采用**均方误差（MSE）** 而非交叉熵，原因是滤波后的MI-EEG中包含大量静息态区间。
