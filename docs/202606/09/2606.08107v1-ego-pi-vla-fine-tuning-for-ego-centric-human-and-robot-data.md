## 摘要
机器人领域面临数据稀缺的根本性挑战。与语言或视觉研究不同，机器人操作缺乏互联网规模的数据集。一条有前景的路径是利用以自我为中心的人类数据，这类数据更容易收集，覆盖面更广，规模更大。为此，我们研究了跨人类和配备灵巧五指手的人形机器人本体的学习关键设计选择，以π_{0.5}模型为基础。我们的结果表明，人类数据使机器人能够在没有相应机器人数据的情况下学习新的任务语义，并将现有技能组合成新颖的行为。论文网站：https://egopipaper.github.io/

## Abstract
Robotics faces a fundamental challenge of data scarcity. Unlike language or vision research, there is no internet-scale dataset for robotic manipulation. A promising path forward is to leverage egocentric human data, which can be collected more easily, with greater breadth, and at a larger scale. Towards this end, we investigate key design choices for learning across human and humanoid embodiments equipped with dexterous five-finger hands, using the $π_{0.5}$ model as a foundation. Our results show that human data enables robots to learn new task semantics and compose existing skills into novel behaviors without corresponding robot data. ## 2. 方法论：核心思想、关键技术细节

- **核心思想**：基于预训练的视觉-语言-动作（VLA）模型 π₀.₅，对其进行微调以同时处理**第一人称人类数据**和**机器人数据**，实现跨本体的任务语义迁移。
- **关键技术细节**：
  - **动作对齐（Action Alignment）**：将人类手部关节角映射到机器人关节空间（使用每关节偏移 δ 和缩放因子 f），避免逆运动学带来的自碰撞和不自然姿态。动作向量 a = {p, r, q}，其中 p 为腕部位置（3维），r 为腕部方向（6维旋转表示），q 为手部关节角（Tesollo 20维，Inspire 6维）。
  - **适应夹爪基 VLA 到灵巧手**：原始 π₀.₅ 最大动作维度为32，而双灵巧手总计58维，无法直接适配。提出**交错动作序列（Interleaved Action Sequence）**：将左右手动作分散到两个动作 token 中，有效表示 H/2 个双步时间步，保持预训练权重不变。
  - **视觉对齐**：在输入图像上叠加彩色骨骼线（每根手指不同颜色），并实现深度感知、前后遮挡正确绘制，帮助模型理解人类与机器人手指的对应关系。
  - **子任务预测（Subtask Prediction）**：作为辅助损失，让 VLM 在预测动作前先输出子任务字符串（如“pick tomato”），强迫模型“先思考后行动”。

## 6. 主要结论与发现
