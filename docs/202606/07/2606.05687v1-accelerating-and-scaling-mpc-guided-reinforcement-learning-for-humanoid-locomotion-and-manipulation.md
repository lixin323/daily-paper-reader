## 摘要
在仿人运动控制中，模型预测控制（MPC）提供了基于物理的预测和约束处理能力，而强化学习（RL）通过大规模仿真实现了鲁棒的全身技能。然而，在RL内部使用MPC通常需要耗时的构建问题或额外的训练开销，使得此类框架在实践中难以证明其价值。本文研究了针对仿人机器人行走与操作的高效训练时MPC引导方法，称为MPC-RL。我们提出了一种基于质心动力学的MPC奖励公式，利用训练时MPC轨迹的引导。为了使该方法在大规模并行RL中实用，我们开发了π^nMPC，一种水平并行且无需构建的批处理GPU MPC求解器，直接处理时变动力学以避免高内存使用和预编译。通过多种比较研究和硬件验证，我们发现MPC-RL在行走和操作技能上取得了优越性能。代码库可在https://github.com/junhengl/mpc-rl获取。

## Abstract
In humanoid motion control, model predictive control (MPC) offers physically grounded prediction and constraint handling, while reinforcement learning (RL) enables robust whole-body skills through large-scale simulation. However, using MPC inside RL often requires time-consuming problem construction or excessive training overhead, making such frameworks difficult to justify in practice. This work studies efficient training-time MPC guidance for humanoid locomotion and manipulation, termed MPC-RL. We introduce a centroidal-dynamics MPC reward formulation that leverages guidance from MPC trajectories in training time. To make this practical in massively parallel RL, we develop $π^n$MPC, a parallel-in-horizon and construction-free batched GPU MPC solver that operates directly on time-varying dynamics to avoid high memory usage and pre-compilation. Through a variety of comparative studies and hardware validations, we have found that MPC-RL achieves superior performance in locomotion and manipulation skills. The code base is available at https://github.com/junhengl/mpc-rl.

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 在RL训练过程中，使用质心动力学MPC（CD-MPC）在线求解预测轨迹，并将这些轨迹转换为结构化的“地标”（landmark）奖励信号，引导策略学习。
- 设计一种**预测置信度加权**的奖励形式：从MPC预测轨迹中提取多个时间点的状态（CoM位置、速度、角动量等），并根据预测误差随预测长度增大的规律，对近端地标赋予更高权重，远端地标赋予更低权重。

### 2.2 关键技术细节

**A. 质心动力学MPC（CD-MPC）**

- 状态空间：质心位置c、线性动量l_G、角动量k_G（共9维）。
- 动力学模型（离散时间）：
  - c_{k+1} = c_k + (Δt/m) l_{G,k}
  - l_{G,k+1} = l_{G,k} + Δt (mg + Σ f_{i,k})
  - k_{G,k+1} = k_{G,k} + Δt Σ ((p_{i,k} - c_k) × f_{i,k} + τ_{i,k})
- 约束：接触力位于接触力锥（CWC）和摩擦锥内；接触点由预编程的Raibert启发式规划。

**B. MPC地标引导奖励**

- 从MPC预测轨迹中选取 N_L 个时间点（例如 N_L = 5，对应预测时域内均匀或特定间隔的步长）。
- 在t时刻，将实际CoM与过去MPC预测中对应t时刻的参考CoM比较，定义误差：
  e^ℓ_c(t) = c_t - \hat{c}_{t-δ_ℓ}(δ_ℓ)
- 奖励函数：
  r_{mpc,c}(t) = exp( - Σ_{ℓ=0}^{N_L-1} α_ℓ ||e^ℓ_c(t)||^2_{Q_c} / σ_c^2 )
  其中 α_ℓ 为预测置信度加权系数（近端大、远端小），例如默认配置 α = {0.5, 0.25, 0.15, 0.07, 0.03}。
- 类似地构建CoM速度、角动量、足部位置、地面反作用力等MPC引导奖励项。

**C. π^nMPC：并行水平且无需构造的批处理GPU MPC求解器**

- 基于πMPC的ADMM结构，扩展至时变动力学。
- 使用**速度形式MPC**：将控制输入增量Δu作为优化变量，提升数值稳定性。
- 创新的**变量分离方案**：引入辅助变量 z_{k+1} = \bar{ξ}_{k+1} 和 v_k = \bar{B}_k Δu_k，将问题分解为三个可在时间步上并行更新的子问题。
- 关键优势：
  - **水平并行**：ADMM更新在各时间步上同时执行，而不是顺序递归（如Riccati）。
  - **无需构造**：直接操作时变的系统矩阵{A_k, B_k, e_k}，无需预先编译稀疏QP或消耗大量VRAM。
- 实现平台：PyTorch和JAX，均支持批处理。
- 加速手段：继承Nesterov加速与重启机制。

**D. PPO训练**

- 策略网络（actor）仅接收本体感知和操纵杆命令（便于硬件部署），评论家（critic）接收特权信息包括MPC预测的CoM和角动量参考。
- 动作空间：29个关节位置的增量δq，经PD控制器输出力矩。
- 奖励结构：标准正则项 + MPC引导项（包括mpc_com, mpc_lin_vel, mpc_ang_mom, mpc_foot, mpc_grf等）。
- 训练环境：4096个并行环境，仿真步长200Hz，控制率50Hz，每幕最长20秒。

**E. 有效惯性基PD增益选择**

- 针对机器人Themis，考虑有效惯性（含下游链路惯性和电机反射惯量），选择较低的自然频率（1-2Hz），避免高频激励导致振荡。公式：K_p = J_eff ω_n^2，K_d = 2ζ J_eff ω_n。

## 6. 主要结论与发现

1. **MPC引导显著提升性能**：MPC-RL在所有行走指标（速度跟踪RMSE、推挤恢复力、约束满足）上均优于纯RL基线。例如，vx RMSE从0.161降至0.128（锥形加权）。
2. **最优MPC配置**：预测水平N=10（一个完整步态周期）、更新率10Hz为最佳组合；更长水平或更高频率带来边际收益甚至下降。
3. **锥形加权优于平均或下一时刻加权**：α的锥形分布（近重远轻）效果最佳，说明了长时域信息需置信度递减使用。
4. **π^nMPC求解器高效可扩展**：在GPU上，π^nMPC比传统的稀疏QP求解器（qpth, qpax）和共识ADMM更快、内存更省，尤其长时域下优势明显；JAX实现比PyTorch更快但内存更高。
5. **操作任务可行**：MPC引导RL使得策略能够学习有力的推箱操作，硬件上推动290kg推车（829%体重），而纯RL基线几乎无法推进。
6. **训练效率**：尽管MPC求解增加每步时间，但训练进展更快（图4中60分钟相同分数时MPC-RL进度最高），总训练时间仍可接受（6小时完成）。

## 7. 优点

- **方法创新**：将训练时MPC引导与预测置信度加权结合，充分利用长时域信息而不增加部署成本；提出π^nMPC实现GPU上水平并行且无需构造的求解，规避传统MPC编译瓶颈。
- **实验设计全面**：在行走和操作两种任务上均进行了细致的消融和对比；硬件验证了高负载能力，证明Sim2Real迁移有效。
- **实用价值**：训练后策略无需依赖MPC即可部署，适合实际机器人应用；代码开源，利于复现和扩展。
- **奖励设计巧妙**：将MPC地标奖励与PPO结合，避免了复杂的奖励工程，同时通过加权机制防止不准确长时域信息误导。
- **求解器贡献**：提供了一种即插即用的高性能批处理MPC求解器，可应用于其他MPC-RL场景。

## 8. 不足与局限

- **模型简化**：CD-MPC依赖降阶质心动力学和预设接触序列（Raibert启发式），无法处理复杂地形中的自选择接触模式或非线性效应（如脚底滑移、履带地面等）。
- **数值限制**：π^nMPC虽高效，但ADMM的收敛性可能受问题条件影响；长时域下（N=400）尽管可行，但精度可能下降。
- **实验覆盖面有限**：
  - 仅在单个机器人平台（Themis V2）上硬件验证，未与其他仿人机器人（如HRP-5, Atlas）对比，通用性存疑。
  - 操作任务仅测试平面推车，未涉及抓取、传送等更复杂操作。
  - 未与在线MPC（测试时使用MPC）的方法直接对比，仅与离线引导的不同方法对比。
- **超参数敏感性**：预测置信度加权系数α、地标数量N_L、惩罚权重Q_c等可能需针对不同任务调整，文中未进行系统灵敏度分析。
