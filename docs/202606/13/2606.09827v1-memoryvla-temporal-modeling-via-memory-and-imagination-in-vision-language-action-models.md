## 摘要
时序建模对于机器人操作至关重要，因为有效控制既需要对过去交互的记忆，也需要对未来状态的想象。然而，大多数VLA模型主要依赖当前观测，因此在长时域、时间依赖的任务中表现不佳。认知科学表明，人类依赖于工作记忆来缓冲短期上下文，海马系统来保存过去经验的 episodic 记忆，以及内部模型来想象可能的未来状态演化。受这些机制启发，我们提出 MemoryVLA++，一个全面的时序建模框架，为VLA模型配备记忆与想象以进行机器人操作。预训练的VLM将当前观测编码为感知和认知令牌，形成工作记忆。这些令牌查询感知-认知记忆库以检索相关历史上下文。该记忆库存储来自过去交互的低层细节和高层语义，并通过冗余感知的整合进行更新。一个世界模型在去噪潜在空间中想象未来状态，并在记忆引导下整合想象潜在表示，形成完整的时序感知令牌。最终令牌条件化一个扩散动作专家，以预测时序一致的动作序列。我们在5个仿真基准和3类真实机器人任务（涵盖3种机器人）上进行了广泛实验，包括通用操作、长时域时间依赖任务、鲁棒性和泛化性。我们的方法在Libero、SimplerEnv、Mikasa-Robo、Calvin、Libero-Plus以及多样化的真实机器人任务上取得了强劲性能，验证了带记忆与想象的全时序建模的有效性。例如，在真实机器人上，它在通用、记忆依赖和想象依赖任务上分别获得了+9%、+26%、+28%的提升。项目页面：https://shihao1895.github.io/MemoryVLA-PP-Web

## Abstract
Temporal modeling is essential for robotic manipulation, as effective control requires both memory of past interactions and imagination of future states. However, most VLA models rely primarily on the current observation and therefore struggle with long-horizon, temporally dependent tasks. Cognitive science suggests that humans rely on working memory to buffer short-lived context, the hippocampal system to preserve episodic memory of past experience, and internal models to imagine possible future state evolution. Inspired by these mechanisms, we propose MemoryVLA++, a full temporal modeling framework that equips VLA models with memory and imagination for robotic manipulation. A pretrained VLM encodes the current observation into perceptual and cognitive tokens, forming working memory. These tokens query a Perceptual-Cognitive Memory Bank to retrieve relevant historical context. This bank stores low-level details and high-level semantics from past interactions, and is updated through redundancy-aware consolidation. A world model imagines future states in a denoising latent space, and the imagined latents are integrated under memory guidance to form full temporal-aware tokens. The resulting tokens condition a diffusion action expert to predict temporally consistent action sequences. We conduct extensive experiments on 5 simulation benchmarks and 3 categories of real-robot tasks across 3 robots, covering general manipulation, long-horizon temporal tasks, robustness, and generalization. Our method achieves strong performance across Libero, SimplerEnv, Mikasa-Robo, Calvin, Libero-Plus, and diverse real-robot tasks, validating the effectiveness of full temporal modeling with memory and imagination. ### 2. 论文提出的方法论

-   **核心思想**：构建一个端到端的VLA框架，将当前感知、历史记忆和未来想象三者融合，形成时间感知的表示，用于指导动作生成。
-   **关键技术细节**：
    1.  **工作记忆（Working Memory）**：
        -   利用预训练的VLM（如Prismatic VLM）将当前图像编码为**感知令牌**（Perceptual tokens，保存细粒度视觉细节）和**认知令牌**（Cognitive token，从指令和LLM推理中提取的高层语义），两者构成“工作记忆”。
    2.  **情景记忆：感知-认知记忆库 (PCMB)**：
        -   设计了一个**感知-认知记忆库**，用于存储过去交互中的低层感知细节和高层认知语义。
        -   **记忆检索**：当前的工作记忆令牌作为查询，通过交叉注意力机制从PCMB中检索相关的历史上下文。
        -   **门控融合**：通过一个可学习的门控机制，自适应地将检索到的历史信息与当前工作记忆融合，生成记忆增强的令牌。
        -   **记忆整合**：当记忆库容量满时，采用**冗余感知的整合策略**，通过合并时序相邻、语义相似度最高的记忆条目来保持记忆库的紧凑性。
    3.  **未来想象：基于世界模型的想象模块**：
        -   采用预训练的**视频生成世界模型（Stable Video Diffusion）**，并针对机器人操作数据微调。
        -   **想象生成**：在VLA训练和推理时，世界模型被冻结，仅用于生成未来状态。它对当前观测进行**部分去噪**，从UNet中间层提取多尺度特征，再通过FPN和注意力机制压缩成紧凑的“想象潜在令牌”，编码决策相关的未来动态。
        -   **记忆引导的想象整合**：记忆增强的感知令牌作为查询，与想象潜在令牌进行交互，通过另一个门控机制，选择性吸收与决策相关的未来信息，同时抑制无关或不可靠的预测，形成最终的**全时间感知令牌**。
    4.  **动作生成：全时间感知动作专家**：
        -   将全时间感知令牌作为条件，输入一个**扩散策略（融合DiT的DDIM模型）** 来预测未来的动作序列。认知令牌提供高层语义导航，感知令牌提供细粒度视觉指导。

    -   额外提供了关于**记忆机制**和**想象机制**的定性可视化分析，以及**推理效率**和**更强VLM骨干网络**的分析。
-   **充分性与公平性**：
    -   **充分性**：总体实验量充足，覆盖了多个维度的评测，证明了方法的有效性。
    -   **公平性**：对比了多个强基线方法，并尽可能复现了它们的性能。实验设置较为规范。但存在一个潜在的不公平点：
        -   **与MemoryVLA对比**：MemoryVLA++在部分想象依赖任务（如Conveyor-Pick）上与MemoryVLA对比是合理的，但在其他任务上，MemoryVLA++的对比基线是CogACT。用户会疑惑MemoryVLA在这些任务上是否也被评测了，结果如何？作者将MemoryVLA与CogACT对比，并将MemoryVLA++与MemoryVLA对比，这在一定程度上是公平的，但若能提供完整的交叉对比表会更清晰。

### 6. 论文的主要结论与发现

-   **主要结论**：MemoryVLA++通过在VLA模型中引入明确的记忆和想象机制，实现了全时间建模，显著提升了机器人在长时域、时序依赖任务上的性能。
-   **关键发现**：
    -   **记忆和想象都至关重要**：单独使用记忆（MemoryVLA）或想象都能带来提升，但两者结合能取得最佳效果。在真实机器人任务上，MemoryVLA++在想象依赖任务上比仅用Memory的MemoryVLA高出12个点。
    -   **性能提升明显**：在Libero上平均成功率达98.4%，在SimplerEnv上相比CogACT提升16.6个点。在真实机器人任务上，在记忆和想象依赖任务上分别提升了26%和28%。
    -   **模块设计有效**：消融实验证实了门控融合、冗余感知整合等关键设计的有效性。
    -   **轻量级与低开销**：记忆模块和潜在空间想象设计在很大程度上保证了推理效率，使其能够用于真实机器人实时控制。

### 7. 优点

-   **方法新颖且系统**：系统性地从认知科学中汲取灵感，构建了包含“记忆”和“想象”的全时间建模VLA框架，概念上有突破性，且模块设计清晰。
-   **实验非常全面**：覆盖了仿真和多样化的真实机器人任务，并进行了详尽的消融和泛化性分析，增强了结果的说服力。
-   **强调透明度与可复现性**：公开了项目主页，提供了丰富的可视化结果（记忆注意力热图、想象轨迹），有助于社区理解和复现。
-   **注重效率**：潜在空间想象避免了显式的像素级视频预测，降低了计算开销；门控融合等设计也考虑了效率，使得框架实用性强。
-   **清晰的贡献迭代**：明确指出了与先前工作MemoryVLA的增量贡献（增加了想象模块、新增了两个基准实验等），展现了研究的演进脉络。

### 8. 不足与局限

-   **计算开销相对较大**：虽然作者优化了效率，并提供了推理延迟数据，但MemoryVLA++相比基线CogACT，其推理延迟增加了约29%（从0.187s到0.241s），GPU内存需求增加了37.5%（从15.8GB到21.7GB）。这在资源受限的机器人平台上可能仍是一个挑战。
-   **对世界模型的依赖**：想象模块依赖于一个独立的视频生成世界模型。虽然被冻结，但其训练质量和泛化能力直接影响下游任务性能。本文在Calvin上直接使用VPP的结果，并未对该模型在Calvin场景下的针对性微调进行说明，这可能是一个潜在的泛化性瓶颈。
-   **真实任务种类有限**：尽管任务数量不少，但主要集中在桌面和抓取操作。对于更复杂、更动态的全身运动或灵巧手操作等，其适用性尚待验证。
-   **缺乏统计显著性检验**：论文展示了性能分数，但未提供置信区间或进行统计显著性检验。例如，在一些任务上MemoryVLA++与MemoryVLA的差距较小，论文未说明这种提升是否具有显著性。
-   **消融实验存在少量空白**：消融实验主要是在单个基准上进行的，未能展示在所有主要基准上的完整消融结果，部分结论的普适性可能稍弱。例如，想象模块的消融仅在Mikasa-Robo上进行。
