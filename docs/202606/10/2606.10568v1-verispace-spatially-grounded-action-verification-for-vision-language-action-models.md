## 摘要
视觉-语言-动作（VLA）模型在机器人操作方面展现出巨大潜力，但其在测试时的可靠性仍受限于一次性动作预测，即使是微小的动作误差也可能导致抓取失败、碰撞或任务进程错误。一个自然的替代方案是为VLA系统配备测试时验证，允许在执行前提出并评估多个候选动作。然而，可靠的动作验证具有挑战性，因为它不仅需要区分候选动作之间的细微几何差异，还需要评估动作是否朝着任务目标有意义的进展。我们提出了VeriSpace，一种用于VLA系统测试时动作选择的3D感知动作验证器。VeriSpace通过两个关键组件评估候选动作：双路径3D注入场景编码（构建一个同时保留视觉语义和显式3D几何的场景表示）和空间基础动作推理（通过推理任务相关的空间关系、几何有效性和预期的目标进展来评估每个动作）。这些组件共同实现了对细微但结果关键的候选动作的更可靠区分，同时与现有的VLA策略完全兼容。在公共基准测试和真实世界机器人操作任务上的实验表明，VeriSpace在基础VLA策略和先前基于验证的方法上均持续提高了决策可靠性，在分布内和分布外设置中都取得了显著改进。

## Abstract
Vision-language-action (VLA) models have shown strong promise for robotic manipulation, but their reliability at test time remains limited by one-shot action prediction, where even small action errors can cause grasp failure, collision, or incorrect task progression. A natural alternative is to equip VLA systems with test-time verification, allowing multiple candidate actions to be proposed and evaluated before execution. However, reliable action verification is challenging because it requires not only distinguishing subtle geometric differences between candidate actions, but also assessing whether an action makes meaningful progress toward the task goal. We present VeriSpace, a 3D-aware action verifier for test-time action selection in VLA systems. VeriSpace evaluates candidate actions through two key components: Dual-Path 3D-Injected Scene Encoding, which constructs a scene representation that jointly preserves visual semantics and explicit 3D geometry, and Spatially-Grounded Action Reasoning, which evaluates each action by reasoning over task-relevant spatial relations, geometric validity, and expected goal progress. Together, these components enable more reliable discrimination between subtle yet outcome-critical action candidates while remaining fully compatible with existing VLA policies. Experiments on public benchmarks and real-world robotic manipulation tasks show that VeriSpace consistently improves decision reliability over both underlying VLA policies and prior verification-based methods, yielding substantial gains in both in-distribution and out-of-distribution settings.

- **核心问题**：当前 Vision-Language-Action (VLA) 模型在测试时多采用一次性（one-shot）动作预测，即仅根据当前观测和指令输出一个动作并立即执行。这种模式缺乏校验机制，微小的动作误差（如位置偏移、姿态偏差）就可能导致抓取失败、碰撞或任务进展错误。尤其在非结构化场景或需要精细空间控制的操纵任务中，可靠性成为部署关键瓶颈。
- **整体意义**：论文主张通过“生成‑验证”（generate-and-verify）范式来替代一次性预测，在测试阶段对多个候选动作进行空间接地评估，从中选择最有可能成功的动作，从而提升 VLA 系统在真实世界环境中的鲁棒性和安全性。

## 2. 论文提出的方法论：核心思想、关键技术细节
- **核心思想**：构建一个 3D 感知的动作验证器 VeriSpace，该验证器基于视觉-语言模型（VLM），对每个候选动作进行**空间接地推理**，同时评估其几何有效性和对任务目标的推进程度，并输出标量评分，用于重排序候选动作。
- **关键技术细节**：
  - **双路径 3D 注入场景编码**：
    - 将 RGB-D 观测通过相机参数反投影至 3D 工作空间，得到稠密 3D 坐标图，再经正弦编码和 MLP 映射为几何嵌入。
    - 构造两条并行的 token 流：
      1. *3D 几何 tokens*：直接将几何嵌入投影到 VLM token 空间，显式表示场景几何结构。
      2. *空间增强视觉 tokens*：用 CLIP 提取 RGB 图像视觉 patch，并与几何嵌入逐元素相加，保留语义的同时注入 3D 几何。
    - 进一步通过**几何引导的局部聚合**（GLA）：基于最远点采样选取种子 token，在其 3D 邻域内利用可学习的空间核函数加权聚合局部特征，使视觉 tokens 融入局部 3D 上下文信息。
  - **空间接地动作推理**：按照三步链式思维（CoT）进行：
    1. **动作空间推理**：识别任务相关实体（被操作物、目标物、机器人末端执行器），分析其相对位置、朝向、接触与间隙，判断动作的几何合法性。
    2. **目标‑进展评估**：分别描述当前场景状态（预动作评估）和预测动作执行后的预期状态（后动作评估），比较两者与目标状态的接近程度，评估动作对任务进度的贡献。
    3. **验证分数估计**：整合上述推理结果，通过轻量 MLP 为每个候选动作输出标量评分。
  - **训练目标**：采用 Bradley‑Terry 偏好损失（对动作对进行排序）和 CoT 交叉熵损失，联合优化。
  - **整体流程**：冻结的 VLA 策略首先采样 k 个候选动作（本文实验默认 k=8），VeriSpace 对每个候选动作进行上述编码与推理，最终选出得分最高的动作执行。

## 3. 实验设计：数据集、基准（Benchmark）、对比方法
- **模拟基准**：
  - **SimplerEnv‑WidowX**：包含 4 个 pick‑and‑place 任务（Eggplant in Basket, Carrot on Plate, Stack Cubes, Spoon on Towel）。训练集采用 BridgeData V2（无官方训练集），直接评估跨域泛化能力。
