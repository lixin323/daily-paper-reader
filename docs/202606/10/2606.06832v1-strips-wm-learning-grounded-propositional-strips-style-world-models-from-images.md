## 摘要
执行长时域视觉操作的机器人观察高维图像，但成功的规划依赖于与动作相关的事实：当前可以做什么以及之后会发生什么变化。一个有用的规划表示应舍弃无关的视觉细节，同时保留动作的适用性和效果。经典任务规划器通过具有前提条件和效果的符号操作符利用这种结构，但从原始视觉经验中获取此类表示仍然具有挑战性。我们研究了一种视觉任务规划设置，其中机器人仅接收图像转换：当前图像、执行的高级动作以及结果图像。在测试时，给定起始图像和目标图像，机器人必须生成一系列达到目标的高级动作。为解决此问题，我们引入了STRIPS-WM，这是一个直接从视觉转换中学习基于图像的STRIPS风格世界模型的框架。STRIPS-WM首先从图像中归纳出一个有限的抽象转换图，然后学习潜在的二值谓词和每个动作标签的一个基础命题操作符。学习到的操作符形成一个具有稀疏前提条件和添加/删除效果的符号动作模型。最后，学习到的谓词被蒸馏到一个视觉编码器中，从而能够直接从新的起始和目标图像进行经典规划。在视觉重排任务上的实验表明，STRIPS-WM在图像到规划的成功率上优于测试的视觉展开、潜在图搜索和潜在符号基线方法。

## Abstract
Robots performing long-horizon visual manipulation observe high-dimensional images, but successful plans depend on action-relevant facts: what can be done now and what changes afterward. A useful planning representation should discard irrelevant visual details while preserving action applicability and effects. Classical task planners exploit this structure through symbolic operators with preconditions and effects, but obtaining such representations from raw visual experience remains challenging. We study a visual task-planning setting in which a robot receives only image transitions: the current image, executed high-level action, and the resulting image. At test time, given a start image and a goal image, the robot must produce a sequence of high-level actions that reaches the goal. To address this problem, we introduce STRIPS-WM, a framework for learning image-grounded STRIPS-style world models directly from visual transitions. STRIPS-WM first induces a finite abstract transition graph from images, then learns latent binary predicates and one grounded propositional operator per action label. The learned operators form a symbolic action model with sparse preconditions and add/delete effects. Finally, the learned predicates are distilled into a visual encoder, enabling classical planning directly from novel start and goal images. Experiments on visual rearrangement tasks show that STRIPS-WM improves image-to-plan success over the tested visual rollout, latent graph-search and latent-symbolic baselines.

## 2. 论文提出的方法论

### 核心思想
STRIPS-WM包含三个主要阶段，对应从图像到符号模型的三层抽象（见图1）：
1. **图像接地任务图**：将观测映射到离散抽象状态，构建状态转移图。
2. **STRIPS算子与谓词学习**：通过CP-SAT求解器，为每个图节点分配二值谓词向量，并为每个动作标签学习一个命题算子（含前件、添加/删除效果）。
3. **视觉谓词分类器**：训练一个视觉编码器将图像直接映射到谓词概率，实现测试时从新图像进行经典规划。

### 关键技术细节
- **阶段1：图像接地任务图**（图2）
  - 学生编码器将观测图像编码为连续向量，经有限标量量化（FSQ）得到离散代码。
  - 教师编码器（EMA更新）为目标代码提供监督。
  - 动作条件潜在动力学模型：给定当前代码和动作标签，预测下一个代码（均方误差损失）。
  - 逆动力学模型：从当前和下一个代码预测动作（交叉熵损失），防止表示塌缩。
  - 训练后，每个图像被分配一个抽象状态ID，得到任务图 ˆG = (ˆS, ˆE)。

- **阶段2：学习STRIPS算子和谓词**
  - 将问题编码为二进制CP-SAT问题。
  - 变量：每个图节点 ˆs 的二值谓词向量 ˆx_{ˆs} ∈ {0,1}^m；每个动作 a 的算子掩码：前件 pre⁺、pre⁻，效果 add、del。
  - 约束：
    - **正例约束**（观察边）：动作在源节点前件成立，且转移后谓词状态满足添加/删除/惯性逻辑。
    - **负例约束**（信任缺失对）：未观察的动作-状态对至少违反一个前件（否则适用性松弛）。
    - **不相交约束**：add与del互斥，pre⁺与pre⁻互斥。
  - 使用松弛变量（ξ 转移松弛、η 适用性松弛）处理图噪声。
  - 优化目标（词法序）：最小化总转移松弛 → 总适用性松弛 → 效果非零数 → 前件非零数。
  - 形式化保证（附录B.2）：每个可行解都生成格式良好的STRIPS算子；零松弛时精确再现观察边并排除信任缺失边（定理10）。

- **阶段3：视觉谓词分类器**
  - 用图像与阶段2获得的谓词向量训练二元分类器（ConvNeXt-Tiny，输出概率）。
  - 测试时：将新起始图像和目标图像经分类器得到二值谓词向量，使用学习到的算子在谓词空间进行经典搜索（如BFS），返回动作序列。

## 3. 实验设计

### 数据集/场景

### 对比方法
- **WM-Rollout**：使用学习到的FSQ潜在动力学模型滚动候选序列，选择与目标代码最接近的。

## 6. 论文的主要结论与发现

1. **STRIPS-WM能从原始图像自动学习正确的命题STRIPS世界模型**：在BlocksWorld中，学习到的谓词和算子完全匹配真实抽象（|ˆS|=|S⋆|=|ˆX|=16，零松弛）。
2. **在长时域规划上显著优于基线**：在超过15步的规划中，STRIPS-WM保持100%成功率，而其他方法迅速下降。
3. **负证据对学习有效前件至关重要**：去掉负证据后，规划失败，因为动作适用性被过度泛化。
4. **CP-SAT能够合并过分割的视觉状态**：在DinnerTable Real中，视觉图有111个节点，CP-SAT坍缩为71个唯一谓词状态，保留正确转移（零过渡松弛）。
5. **符号表示比平坦图搜索更鲁棒**：STRIPS-WM比直接在图搜索（WM-BFS）更成功，因为算子学习能纠正图中的不一致性并使感知任务简化（预测m个谓词而非111个节点类）。

## 7. 优点

- **完全自监督**：无需对象ID、分割、姿态、手工谓词或符号目标标签，直接从图像-动作-图像三元组学习。
- **生成紧凑可解释的符号模型**：学习到的谓词数量少（m=9或35），算子具有稀疏前件和效果，易于检查和调试。
- **利用经典规划器保证**：一旦获得符号模型，规划是离散、可确定、可回溯的，非神经滚动预测。
- **处理视觉过分割和噪声**：CP-SAT松弛机制允许图不精确时仍学到正确抽象（如DinnerTable Real）。
- **可迁移到真实图像**：在带干扰物的真实场景中成功规划，展示了从仿真到真实的泛化潜力。

## 8. 不足与局限

- **假设确定性STRIPS动力学**：不适用于随机效果或部分可观测场景。真实机器人动作常有随机性，未建模隐状态。
- **依赖任务图质量和覆盖度**：视觉别名（不同状态映射到同一代码）或不完整动作覆盖会导致错误的前件或负证据，从而影响算子质量。
- **限于命题算子**：学习的是接地命题操作符，而非一阶关系模式，因此无法组合泛化到新物体或新参数，需要额外数据重新训练。
- **实验域有限**：仅测试三种物体重排任务（搬砖、桌子摆物体），未验证更复杂任务（如运动规划、不确定性动作、非刚体物体）。
- **算力要求未明晰**：未提供训练所需GPU具体型号和总时长，难以评估实际部署成本。
- **未消融各组件贡献**：如JEPA架构、FSQ量化、稀疏性目标等单个组件的必要性未通过实验分离验证。
