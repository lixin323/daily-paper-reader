## 摘要
世界动作模型（WAMs）已成为具身智能的一种新的强大范式，学习与动作相关的视觉动态，显著增强了泛化性和鲁棒性。然而，现有的WAMs在长时程机器人操作中仍难以处理任务相关的记忆。为解决这一问题，我们提出了HiMem-WAM，一种层次化记忆门控WAM，它整合了以运动为中心的潜在动作、高层技能潜变量以及边界触发的记忆更新。具体而言，我们开发了一个层次化潜在动作框架，联合学习底层运动和高层技能潜变量，提供结构化的时间抽象。同时，边界感知记忆门在预测的技能转换处写入紧凑的任务状态，从而无需在测试时生成未来视频或光流估计即可实现因果推理。在LIBERO、LIBERO-PLUS、RMBench以及真实世界任务上的评估表明，HiMem-WAM中层次化潜变量提高了部署扰动下的鲁棒性，而记忆模块显著有益于依赖记忆的长时程操作。

## Abstract
World Action Models (WAMs) have emerged as a new powerful paradigm for embodied intelligence, learning action-relevant visual dynamics that significantly enhance generalization and robustness. However, existing WAMs still struggle with task-relevant memory in long-horizon robotic manipulation. To address this, we present HiMem-WAM, a Hierarchical Memory-Gated WAM that integrates motion-centric latent actions, high-level skill latents, and boundary-triggered memory updates. Specifically, we develop a hierarchical latent action framework that jointly learns low-level motion and high-level skill latents, providing structured temporal abstraction. Meanwhile, a boundary-aware memory gate writes compact task states at predicted skill transitions, enabling causal inference without test-time generation of future video or optical flow estimation. Evaluated on LIBERO, LIBERO-PLUS, RMBench and real-world tasks, HiMem-WAM shows that hierarchical latents improve robustness under deployment perturbations, and the memory module substantially benefits memory-dependent long-horizon manipulation.

- **研究背景**：
  - VLA 模型（如 RT-2、OpenVLA）虽能进行语言条件操作，但端到端动作预测缺乏鲁棒性，且难以维护长时序任务历史。
  - WAM（如 MotuBrain、LingBot-VA）通过未来预测或潜在动力学建模提供更强的动力学先验，提升泛化性，但在长程任务中仍依赖密集历史聚合或测试时视频生成。
  - 针对长程记忆问题，RM-Bench 等基准揭示了固定长度历史窗口的不足，现有方法如 MemoryVLA、MemER 引入记忆，但多采用密集存储或固定窗口。
- **整体含义**：本文提出 HiMem-WAM，将低层运动与高层技能进行层次化分解，并在技能转换处使用门控记忆模块存储紧凑任务状态，实现因果、高效的长时程操作。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
- 将策略分解为三个层次：
  1. **高层技能潜变量** (skill latent)：表示当前子任务（如“抓取碗”）。
  2. **低层潜在动作块** (low-level latent action chunk)：表示短期运动序列。
  3. **实际动作解码**：将潜在动作映射为可执行的控制信号。
- 记忆模块仅在检测到技能边界（即子任务切换）时写入紧凑状态，读取时通过门控自适应融合历史信息。

### 关键技术细节

#### 低层潜在动作（Low-level Latent Actions）
- 从多视图 RGB 图像提取光流（DPFlow），用变分编码器编码短时上下文（包含当前帧、下一帧、光流、指令等），得到低层潜变量 \(z^l_t\)。
- 训练损失：光流重建 L1 损失 + 可选动作对齐损失（如果动作标签可用）+ KL 散度正则。

#### 高层技能潜变量（High-level Skill Latents）
- 对低层序列进行层次化 chunk 操作：通过边界预测器（dissimilarity score）和注意力池化，逐步将原始长序列划分为可变长度的段落，最终得到技能序列 \(z^h_1,\dots,z^h_S\)。
- 利用技能发现损失（包括下一潜变量预测、光流重建、边界比率正则和一致性正则）进行无监督训练。

#### 记忆门控模块（Memory-gated Module）
- **读取门**：将当前状态 \(x_t\) 与记忆库 \(M_t\) 进行注意力交互，得到检索上下文 \(c^m_t\)，通过 sigmoid 门控 \(\alpha^r_t\) 控制融合强度。
- **写入门**：基于当前状态、预测技能和边界分数 \(\hat{b}_t\)，计算写入门 \(\alpha^w_t\)，只有当 \(\alpha^w_t > \eta\) 时才写入新的记忆令牌。写入监督信号来自技能发现阶段得到的边界标签 \(\bar{b}_t\)。
- 记忆库保持固定容量，超限时进行压缩。

#### 训练流程（三阶段）
- **Stage I**：训练低层潜变量 tokenizer（使用光流和可选动作标签）。
- **Stage II**：冻结 tokenizer，进行高层技能发现和预训练规划器（planner，Qwen3-VL-4B-Instruct）与执行器（executor），不使用外部记忆。
- **Stage III**：激活记忆模块，对全策略进行微调，优化动作损失、规划损失、执行损失、边界损失和门控损失。

#### 推理
- 完全因果：仅需当前 RGB、本体感知、指令和记忆库。不生成未来视频或光流。步骤：读取记忆 → 预测技能 → 展开潜在动作块 → 解码为动作 → 按写入门条件更新记忆。

## 3. 实验设计：使用的数据集/场景、benchmark、对比方法

### 仿真基准
- **LIBERO**：包含空间、物体、目标、长程四个子套件，每任务 50 轮评估。
- **LIBERO-PLUS**：零样本泛化测试，引入 7 种部署扰动（相机、初始状态、语言、光照、背景、噪声、布局），仅用标准 LIBERO 数据训练。
- **RMBench**：包含 9 个记忆依赖操作任务，分为 M(1)（单次记忆）和 M(n)（多次记忆）两种复杂度，每任务 100 轮评估。

### 真实世界实验
- **硬件平台**：双六轴 AgileX Piper 机械臂，配备 4 个 Intel RealSense D435i 相机。
- **任务设置**：10 个任务，按难度分为 Easy (4个)、Medium (4个)、Hard (2个)。每个任务 400 条演示。
- **评估设置**：标准 (ST) 与泛化 (GE) 两种条件，GE 包含物体位置变化、未见干扰物、布局高度变化、光照变化、指令变化等。每任务 20 次试验。

### 对比方法
- VLA 类：OpenVLA、π0/π0.5、X-VLA、AtomVLA、SpatialVLA、UniVLA、NORA-1.5 等。
- WAM 类：WorldVLA、Fast-WAM、LingBot-VA、HoloBrain-0 等。
- 其他：DP、ACT、RIPT-VLA、MEM-0 等。

## 6. 论文的主要结论与发现

1. **层次潜动作提升鲁棒性**：Stage II 预训练在 LIBERO 上 +1.1%，在 LIBERO-PLUS（零样本扰动）上 +3.8%，表明潜在运动先验能防止过拟合于干净视觉轨迹。
2. **门控记忆改善记忆依赖任务**：在 RMBench 上达到 26.3% 平均成功率（M(1) 31.6%），显著高于 DP、ACT、π0.5、X-VLA 等无记忆基线，验证了边界触发的稀疏记忆机制有效。
3. **真实世界推广优势**：在 Medium 和 Hard 任务中，HiMem-WAM 较 π0.5 分别提升 +10% 和 +20%，尤其长程硬任务中记忆门控帮助追踪任务进度。
4. **层次潜动作跨表征有效**：无论使用关节位置还是末端位姿动作表征，Stage II 预训练均带来增益，且对任务空间命令提升更大。

## 7. 优点：方法或实验设计上的亮点

- **方法设计**：
  - 将记忆写入与技能边界绑定，避免密集存储，同时保持因果推理（不依赖未来视频生成）。
  - 层次化潜动作结构自然分离“做什么（技能）”与“怎么做（运动）”，便于迁移和组合。
  - 利用无监督光流和视频数据学习低层潜动作，减少对动作标签的依赖。
- **实验设计**：
  - 在标准 benchmark 之外，专门构造记忆依赖的 RMBench 和含多种扰动的 LIBERO-PLUS，全面评估鲁棒性和记忆能力。
  - 真实世界实验包含三档难度和两个评估设定（ST/GE），基线包括最强通用模型 π0.5，结果具有说服力。
  - 消融实验覆盖了关键模块（Stage II 预训练、记忆门控），并考察了动作表征影响。

## 8. 不足与局限

- **计算开销大**：训练需三个阶段，Stage I 需提取多视图光流，Stage II 进行层次技能发现，Stage III 微调 4B 规划器，总体算力需求高，且文中未报告具体硬件配置和耗时。
- **多阶段工程复杂性**：性能依赖于各阶段质量（光流、潜动作、技能边界、记忆更新），各阶段误差可能累积。
- **记忆推理能力有限**：在 RMBench 的 M(n) 任务（需多轮记忆更新）上低于专门设计的 MEM-0，提示当前门控机制对复杂推理场景支持不足。
- **真实世界评估范围有限**：仅在一个双机械臂平台上测试 10 个任务，缺少多样本科目（如移动操作、灵巧手）和更大场景规模下的验证。
- **对比公平性**：HiMem-WAM 使用了 4B 参数的 Qwen3-VL-4B 作为规划器，而部分缩小的基线（如 π0.5 为 7B）参数更多，但作者并未讨论性能与参数量的权衡。
