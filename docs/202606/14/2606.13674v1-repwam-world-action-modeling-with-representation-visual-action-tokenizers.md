## 摘要
本文提出RepWAM，一种基于表示视觉-动作分词器的以表示为中心的世界动作模型（WAM）。现有的WAM通常从预训练的视频生成模型中继承面向重构的视频分词器。尽管这些分词器保留了视觉保真度，但仅靠像素重构对于学习将未来预测与机器人控制相连接的指令跟随动态所提供的指导有限。为解决这一问题，我们探索了一种用于以表示为中心的世界动作建模的语义视觉-动作潜在空间。具体而言，我们训练了一个表示视觉-动作分词器，将视觉输入映射为对齐的视觉和潜在动作标记。然后，我们预训练WAM以联合建模未来视觉状态以及连接这些状态的语言指令下的潜在动作，随后将其适应到真实机器人轨迹以实现闭环操作。在真实世界操作任务和仿真基准上的实验表明，RepWAM在多种操作设置中表现出强劲性能，而消融实验则凸显了语义视觉-动作分词相对于面向重构替代方案的价值。这些结果确立了表示视觉-动作分词作为世界动作模型有前景的基础，并朝着通用机器人策略迈出了一步。代码和权重将发布于https://github.com/wdrink/RepWAM。

## Abstract
This work presents RepWAM, a representation-centric world action model (WAM) built on representation visual-action tokenizers. Existing WAMs typically inherit reconstruction-oriented video tokenizers from pretrained video generation models. Although these tokenizers preserve visual fidelity, pixel reconstruction alone provides limited guidance for learning instruction-following dynamics that connect future prediction with robot control. To address this, we explore a semantic visual-action latent space for representation-centric world action modeling. Specifically, we train a representation visual-action tokenizer that maps visual inputs into aligned visual and latent action tokens. We then pretrain our WAM to jointly model future visual states and the latent actions that connect them under language instructions, followed by adaptation to real robot trajectories for closed-loop manipulation. Experiments on real-world manipulation tasks and simulation benchmarks show that RepWAM delivers strong performance across diverse manipulation settings, while ablations highlight the value of semantic visual-action tokenization over reconstruction-oriented alternatives. These results establish representation visual-action tokenization as a promising foundation for world action models and a step toward generalist robot policies. Code and weights will be available at https://github.com/wdrink/RepWAM.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有世界动作模型（WAM）通常从预训练的视频生成模型中继承面向**像素重建**的视频分词器（如 WAN2.2 VAE）。这类分词器虽能保持视觉保真度，但其潜在空间优化的是低层外观（如背景纹理），而非任务相关的语义信息或机器人动作。这导致两个缺陷：
  - 视觉上，潜在表示被外观变化主导，难以有效学习指令跟随的动态（如物体交互）。
  - 动作上，视觉潜变量与电机指令处于分离的空间，迫使逆动力学模型（IDM）每一步都要弥补模态鸿沟。
- **整体含义**：论文提出**应该为 WAM 设计语义化的视觉-动作联合潜在空间**，使视觉状态和动作引发的转换在同一空间内表示，从而提升未来预测和机器人控制的性能。

## 6. 论文的主要结论与发现

- 表示视觉-动作分词化（RepViTok）显著提升 WAM 性能，在真实和仿真任务上均优于面向重建的分词器（WAN2.2 VAE、ViTok）。
- 语义对齐的视觉潜空间使 WAM 能更好学习指令跟随的动态，提升开放循环动作准确率和闭环执行成功率。
- 潜在动作分词器在语义潜空间中描述状态转换，比重建导向的方法更聚焦于操作相关变化，且更易映射为机器人动作。
- 两阶段训练（先预训练 WAM 使用潜在动作，再适应到真实动作）优于无潜在动作或联合预测，说明解耦潜在动作预训练是有益的。
- RepViTok 降低了对视频分类器自由引导（CFG）的依赖（在 CFG=1.0 时表现最好），从而减少推理延迟和激活内存。

## 7. 优点

- **创新性**：首次提出为世界动作模型设计语义化的视觉-动作联合潜在空间，直接解决了重建导向分词器的根本局限。
- **方法设计巧妙**：特征对齐损失将潜空间拉向冻结语义模型，潜在动作通过传输矩阵+残差描述状态转换，具有可解释性且与视觉一致。
- **实验全面且有说服力**：从真实机器人到仿真、从短时到长时任务、从视觉生成到动作预测，系统性地验证了贡献。
- **开源承诺**：代码和权重将公开，有利于社区复现和后续研究。
- **性能提升显著**：在真实操作任务上，5B 模型在长时和精细任务上比 π0.5 提升 30-50 个百分点，比 Lingbot-VA 提升 10-20 个百分点。
- **消融实验控制得当**：例如固定 1.3B WAM 仅换 tokenizer，公平比较。

## 8. 不足与局限

- **平台单一性**：真实世界实验仅使用 Franka 双机械臂，未验证在其他机器人平台（如单臂、移动操纵）的泛化性。

- **数据需求大**：适应阶段需要 300G tokens 的机器人演示数据，依赖大规模高质量数据集，这可能限制在数据稀缺场景的应用。
- **计算资源消耗高**：5B 模型需 128 块 H20 GPU 训练，消融实验也需 32 块 GPU，不利于小型团队复现。
- **未探索跨实体泛化**：论文专注于单一平台适应，未展示学习到的潜在动作表示能否跨不同机器人形态迁移。
