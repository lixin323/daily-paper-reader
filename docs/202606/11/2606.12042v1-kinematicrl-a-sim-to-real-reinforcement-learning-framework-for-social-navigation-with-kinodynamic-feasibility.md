## 摘要
深度强化学习（DRL）在社交导航中展现出了潜力，但其实际部署仍受到持续存在的仿真到现实差距的阻碍，这种差距源于简化的一阶动力学和针对特定上下文的人体状态估计流程。本文提出一个统一的框架来解决这些限制，以生成适合实际部署的动态可行导航策略。首先，理论分析表明，模拟机器人位置与实际机器人位置之间的跟踪误差随着控制阶数的增加而呈指数衰减，这促使使用高阶控制输入作为DRL动作空间。针对差速驱动机器人开发了二阶控制公式，并辅以随机迭代线性二次型调节器（iLQR），通过散度最小化目标预训练策略。其次，为避免相机-激光雷达融合带来的额外系统复杂性，引入了一种仅使用2D激光雷达的基于聚类的人体追踪流程。根据空间接近度和速度相似性关联人体检测，从而可靠地区分附近行人，并通过时间聚合获得稳定的速度估计。第三，我们引入了一个无偏残差门控模块，以平衡基于反应和记忆的行为，同时处理时变的人群规模，这两者对社交导航都至关重要。由此产生的策略KinematicRL持续改善了运动学性能，并适应不同数量的检测到的人。在实际环境中的实验表明，当与所提出的追踪流程结合时，KinematicRL可以以最小的修改部署在真实的差速驱动机器人上。

## Abstract
Deep Reinforcement Learning (DRL) has shown promise for social navigation, yet its real-world deployment remains hindered by a persistent sim-to-real gap arising from simplified first-order dynamics and context-specific human state estimation pipelines. This work presents a unified framework that addresses these limitations to produce dynamically feasible navigation policies suitable for real-world deployment. First, theoretical analysis reveals that tracking error between simulated and actual robot position decays exponentially with increased control order, motivating the use of higher-order control inputs as DRL action space. A second-order control formulation tailored to differential drive robots is developed, complemented by a stochastic iterative Linear Quadratic Regulator (iLQR) that pretrains the policy via a divergence minimization objective. Second, to avoid the added system complexity of camera-LiDAR fusion, a cluster-based human tracking pipeline using only 2D LiDAR is introduced. Human detections are associated according to both spatial proximity and velocity similarity, enabling reliable differentiation of nearby pedestrians and yielding stable velocity estimates through temporal aggregation. Third, we introduce an unbiased residual gating block to balance reaction- and memory-based behaviors while handling time-varying crowd sizes, both critical for social navigation. The resulting policy, KinematicRL, consistently improves kinematic performance and adapts to varying number of detected humans. Experiments in real-world environments demonstrate that, when combined with the proposed tracking pipeline, KinematicRL can be deployed on a real differential drive robot with minimal modifications.

- **核心问题**：深度强化学习（DRL）在社交导航任务中展现出潜力，但在真实世界部署时面临严重的 **sim-to-real（仿真到现实）差距**。该差距主要源于两点：
    1.  **简化动力学模型**：大多数 DRL 方法在仿真中采用理想化的**一阶动力学**（即时速度指令跟踪），而真实机器人受限于物理执行器，无法瞬间实现指令速度变化，导致控制指令实际不可行。

- **整体含义**：本文旨在构建一个统一的 **KinematicRL 框架**，通过解决上述两个关键差距，使得在仿真中训练的社交导航策略能够**在真实机器人上直接部署**，同时保证最终的轨迹是**动态可行且符合运动学约束**（如加速度限制）的。

### 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：通过 **高阶控制** 来解决动态可行性问题，通过 **2D LiDAR 聚类跟踪** 简化感知，通过 **无偏残差门控 Transformer** 处理变长人群输入。
- **关键技术细节**：
    1.  **高阶控制用于动态可行性**：
        - **理论分析**：定义 `n` 阶控制（`x^(n)` 为控制输入），证明**跟踪误差**（仿真位置与真实位置之差）随控制阶数 `n` 增加而**指数级衰减**（`O(Δt^(n-k) / (n-k)!)`）。
        - **实用选择**：针对差速驱动机器人，采用 **二阶控制**（加速度 `ua, uα`）作为 DRL 动作空间（`A = {(ua, uα) | ua ∈ [amin, amax], uα ∈ [αmin, αmax]}`），自然满足加速度约束，是性能和复杂度的平衡点。
        - **策略初始化**：引入**随机 iLQR（迭代线性二次型调节器）**。该算法为最大熵控制器，输出一个高斯分布 `N(μ, Σ)`。通过最小化**前向 KL 散度（M-投影）** 进行模仿学习（Behavioral Cloning），将 iLQR 的分布信息（包括协方差，代表动作不确定性）传递给策略网络，从而更高效地初始化策略，加速后续强化学习训练。
    2.  **基于聚类的 LiDAR 追踪管道**：
        - **位置检测**：使用 **Li2Former** 网络从 2D LiDAR 点云中估计行人中心坐标。
        - **数据关联**：提出**空间-速度相似性**结合的距离度量 `J( p̂, C ) = (1-α) * 位置距离 + α * 速度距离`，使用**匈牙利算法**进行最优分配，能有效区分空间靠近但运动速度不同的行人。
        - **状态估计**：每个行人作为**聚类簇**维护，使用**历史加权平均**（簇中心位置为最新检测，速度通过时间加权平均）获得平滑稳定的速度和位置估计，减少传感器噪声振动。
    3.  **无偏残差门控 Transformer 架构**：
        - **问题**：标准 Transformer 在 DRL 中初始化不稳定（无法从马尔可夫策略开始），且残差连接不能自适应平衡反应式（当前时刻）和记忆式（历史信息）行为。
        - **模块设计**：采用 **GRU** 替代原始 Transformer 的加法残差连接。GRU 通过学习到的门控值（`Γu`）来**动态调节**注意力流（记忆路径）和残差流（反应路径）的混合。
        - **关键改进**：
            - **移除 GRU 偏置项 `bu`**：避免因填充（padding）可变长输入而引入偏差。
            - **修改残差连接**：使第二层 GRU 的跳跃连接直接来自输入嵌入而非中间状态，缓解了信号衰减（`0.25x` → `0.5x` 每层），提升了信息保留。
            - **场景域随机化**：为使 Transformer 学到主动而非被动的策略，引入高多样性的训练场景（随机化行人初始位置、速度和目标方向），防止注意力机制退化为将所有行人视为整体。
