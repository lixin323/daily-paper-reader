## 摘要
流匹配已成为机器人操作的标准范式，因为它具有对复杂多模态动作分布建模的强大表达能力，与扩散策略等类似方法类似。然而，现有方法依赖于离散化的动作片段，这使得它们难以处理以异构控制频率收集的演示数据，并且容易产生时间上不一致的动作，从而降低控制稳定性。在本文中，我们提出了频率感知的流匹配（FAFM），该算法输出连续、时间一致的动作。为了处理异构频率输入，我们使用离散余弦变换（DCT）将离散动作序列变换到频域，对所得系数进行流匹配，并通过余弦基展开重构连续动作。为了生成时间一致的动作，我们对一阶时间导数进行正则化以促进动作平滑。这对应于一种Sobolev型约束，能够抑制高频误差并阻止动作突变。我们的FAFM方法简单，不引入额外网络参数，并适用于独立的流匹配策略和视觉-语言动作模型。在合成玩具基准、避障、LapGym和LIBERO上，FAFM提高了成功率、多模态表达能力、运动平滑性、收敛速度、对机械偏差和混合频率输入的鲁棒性。这些增益在实际的Franka机器人上部署时保持一致。代码可在https://anonymous.4open.science/r/FAFM获取。

## Abstract
Flow matching has emerged as a standard paradigm for robotic manipulation owing to its strong expressive power for modelling complex, multimodal action distributions, alongside similar approaches like diffusion policy. However, existing methods rely on discretized action chunks, making them brittle to demonstrations collected at heterogeneous control frequencies and prone to temporally inconsistent actions that degrade control stability. In this paper, we propose Frequency-Aware Flow Matching (FAFM), which outputs continuous, temporally consistent actions. To handle heterogeneous frequency input, we transform discrete action sequences into the frequency domain with the discrete cosine transform (DCT), perform flow matching over the resulting coefficients, and reconstruct continuous actions via cosine basis expansion. To generate temporally consistent actions, we regularize the first-order temporal derivative to promote smooth actions. This corresponds to a Sobolev-type constraint that suppresses high-frequency errors and discourages abrupt action changes. Our FAFM is simple, introduces no additional network parameters and applies to standalone flow-matching policies and vision-language action models. Across synthetic toy benchmark, obstacle avoidance, LapGym, and LIBERO, FAFM improves success rates, multimodal expressivity, motion smoothness, convergence speed, robustness to mechanical bias and mixed-frequency input. These gains are consistent when deployed on a real-world Franka robot. Code available at https://anonymous.4open.science/r/FAFM.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究动机**：现有基于流匹配（Flow Matching）的机器人动作生成策略（如扩散策略）依赖于离散化的“动作块”（action chunk），即在一段固定时间窗口内预测一系列离散动作步。这种方式存在两大问题：
  1. 训练时，演示数据常以不同控制频率采集（如 3 Hz 至 50 Hz），但策略要求以单一固定频率输出动作块，导致“异频梯度冲突”——相同物理轨迹在不同频率下会产生不同长度和幅值的动作块，使得学习目标不一致。
  2. 推理时，动作块内相邻步是独立预测的，缺乏时间一致性，容易产生高频抖动（jitter）或方向相反的突变，影响控制稳定性，尤其在软体操作（如液体倾倒、手术组织操作）中会导致不可逆的失败。
- **整体含义**：需要一种能够直接输出连续、时间一致动作的方法，同时兼容异构频率的训练数据，无需增加额外参数。

## 2. 方法论

- **核心思想**：将离散动作序列通过离散余弦变换（DCT）映射到频域，在频域进行流匹配，再利用余弦基展开重建任意时刻的连续动作；同时正则化一阶时间导数以促进平滑性，对应 Sobolev 约束。
- **关键技术细节**：
  1. **连续动作生成**：
     - 对每个固定物理时间长度 \(T_\xi\) 的轨迹，使用 DCT-II 将其转换为 \(M+1\) 个系数向量 \(\hat{c} \in \mathbb{R}^{(M+1)\times d}\)（\(M \ll K\)，\(K\) 为离散步数）。
     - DCT 系数仅依赖物理时间，不依赖采样频率，因此不同频率的同一轨迹产生几乎相同的系数目标，解决了“异频梯度冲突”问题（Proposition 1）。
     - 流匹配在系数空间进行：\(\hat{c}_t = t \hat{c}^* + (1-t)\varepsilon\)，训练目标为 \(\mathbb{E}[ \| v_\theta(\hat{c}_t, o, t) - (\hat{c}^* - \varepsilon) \|^2 ]\)。
     - 推理时通过 ODE 积分得到系数，再通过余弦基展开 \(\hat{v}(\tau) = \frac{1}{2}\hat{c}_0 + \sum_{j=1}^M \hat{c}_j \cos(\omega_j \tau)\) 重建任意时间分辨率下的连续动作。
  2. **时间一致动作**：
     - 基于 DCT 的连续表示可以直接解析计算一阶时间导数 \(\dot{\hat{v}}(\tau) = -\sum_{j=1}^M \hat{c}_j \omega_j \sin(\omega_j \tau)\)，避免有限差分噪声。
     - 增加速度损失 \(L_{\text{vel}} = \mathbb{E}[ \|\dot{\hat{v}}(\tau_k) - \dot{\xi}(\tau_k)\|^2 ]\)，与动作损失 \(L_{\text{FM}}\) 联合优化：\(L_{\text{FAFM}} = L_{\text{FM}} + \lambda L_{\text{vel}}\)，默认 \(\lambda=1\)。
  3. **理论理解**：
     - FAFM 损失等价于 Sobolev \(\mathrm{H}^1_\mu\) 范数下的投影误差：\(\sum_{j=0}^M (1 + \lambda \omega_j^2) \delta_j^2\)（\(\delta_j\) 为系数预测误差）。高频系数误差被 \(\omega_j^2\) 加权放大，从而有效抑制高频抖动。
     - 该损失天然充当频谱预处理器，加速收敛；并对恒定机械偏置具有鲁棒性（偏置仅影响 DC 系数，不影响形状系数）。
- **实现优势**：不引入额外网络参数，可直接应用于现有流匹配策略或 VLA 的动作头。
