## 摘要
自动化奖励设计（ARD）旨在通过语言驱动的奖励函数合成，替代强化学习中的人工奖励工程。然而，现有基于大型语言模型（LLM）的方法本质上仍是相关性驱动的，依赖迭代环境反馈来为每个特定任务优化奖励假设。这种范式不仅导致推理效率低下，还使LLM容易受到语义上合理但因果上虚假的奖励成分的影响，从而导致优化失效。为克服这些局限，我们提出因果奖励世界模型（CRWM），该模型通过在多任务交互数据上进行离线预训练，显式建模候选奖励成分与目标任务物理变量之间的因果拓扑关系。基于由粗到细的预训练策略，我们引入了一个联合优化模块，该模块将显式机制解耦与置信感知软融合相结合，利用微观轨迹细化粗结构先验，从而构建鲁棒且可解释的因果骨架。在推理阶段，LLM将CRWM作为任务无关的因果先验来约束奖励生成，实现零样本奖励函数设计。我们的工作为ARD问题开辟了新的白盒范式。在复杂连续控制基准上的大量实验表明，CRWM无需基于反馈的奖励优化即可生成可执行的奖励函数，显著降低了获取新机器人技能的设计延迟，同时达到或超越最先进性能，并在未见任务和不同机器人形态中展现出强大的泛化能力。

## Abstract
Automated Reward Design (ARD) aims to replace manual reward engineering in reinforcement learning with language-driven reward function synthesis. However, existing approaches based on large language models (LLMs) remain inherently correlation-driven, relying on iterative environmental feedback to refine reward hypotheses for each specific task. This paradigm not only results in inefficient reasoning but also makes LLMs susceptible to semantically plausible yet causally spurious reward components, leading to ineffective optimization. To address these limitations, we propose the Causal Reward World Model (CRWM), which explicitly models the causal topological relationships between candidate reward components and task-targeted physical variables through offline pre-training on multi-task interaction data. Based on a coarse-to-fine pre-training strategy, we introduce a joint optimization module that integrates Explicit Mechanism Decoupling with Confidence-Aware Soft Fusion to refine coarse structural priors using micro-level trajectories, thereby constructing a robust and interpretable causal skeleton. During inference, LLMs leverage CRWM as a task-irrelevant causal prior to constrain the reward generation, enabling zero-shot reward function design. Our work opens up a new white-box paradigm for the ARD problem. Extensive experiments on complex continuous control benchmarks demonstrate that CRWM generates executable reward functions without feedback-driven reward refinement, significantly reducing the design latency for acquiring new robotic skills while matching or surpassing state-of-the-art performance, and further exhibits strong generalization capabilities across unseen tasks and diverse robotic embodiments.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题背景**：自动化奖励设计（ARD）旨在用语言驱动生成奖励函数，替代强化学习中的人工奖励工程。现有基于 LLM 的方法（如 Eureka、URDP）依赖**迭代环境反馈**（trial-and-error）来优化候选奖励，推理效率低，且 LLM 倾向语义关联而非因果关联，容易引入**语义上合理但因果虚假**的奖励成分。
- **具体失效模式**：
  - **优化崩溃（Optimization Collapse）**：虚假相关成分（如瞬时速度）引入高频噪声，导致梯度崩溃，训练停滞。
  - **规范博弈（Specification Gaming）**：智能体利用虚假信号（如“保持剪刀微开”）获得高奖励，但未完成真实任务。
- **核心动机**：能否通过**离线多任务预训练**提取奖励成分与任务目标之间的因果拓扑，作为任务无关的因果先验，使 LLM 在推理时无需迭代反馈，直接零样本生成有效奖励函数。

## 2. 方法论：核心思想与关键技术
### 总体架构：CRWM（Causal Reward World Model）
采用“粗到细”的预训练策略，从多任务交互数据中蒸馏出一个可复用的因果骨架（CRWM），推理时将其作为显式因果先验约束 LLM 的奖励代码生成。

### 2.1 粗结构先验提取（Structural Prior Extraction）
- **分层数据收集**：利用现有 ARD 框架（Eureka、URDP）提取每个任务的物理意义奖励成分（如距离、力、速度），经**任务无关名称归一化**映射到全局共享的结构变量集合 V（d 维，如物体位置、速度、接触力）。
- **宏观干预数据 Dmacro**：对每个任务的奖励成分系数进行 do-操作（均匀采样 30 组权重），训练策略并记录最终适应度分数（如成功率），构成 (权重, 分数) 对。
- **微观轨迹数据 Dmicro**：同步记录每个策略运行中结构变量的逐时间步状态 st ∈ R^d。
- **因果基础模型 LimiX**：输入 Dmacro，输出原始因果效应矩阵 Mraw，进而得到粗结构先验 Mprior（含边方向）和置信矩阵 Mconf（归一化效应幅度）。

### 2.2 联合优化模块（Joint Optimization Module）—— 细化粗先验
- **显式机制解耦（EMD）**：将瞬时拓扑 Minst(st-1) 分解为**可学习因果骨架 Minv**（用于奖励生成后的保留）与**状态依赖瞬态分量 Mtrans(st-1;θ)**（MLP 参数化）的哈达玛积：  
  `Minst(st-1) = Minv ⊙ (1 + Mtrans(st-1;θ))`  
  从而在重建微观轨迹时，瞬态交互由 Mtrans 捕获，不影响 Minv 的稳定结构。
- **置信感知软融合（Confidence-Aware Soft Fusion）**：损失项 `Lsoft = γ ||Mconf ⊙ (Minv - Mprior)||_F^2`，让高置信度的结构先验得到较强约束，低置信度边则更灵活，避免硬约束继承虚假结构。
- **整体优化目标**：  
  `min L = MSE + λ h(Minv) + Lsoft`  
  其中 MSE 为局部线性重建损失，h(Minv) 为 DAGMA 无环正则项，λ 和 γ 为超参数。采用增广拉格朗日方法（ALM）求解。
- **收敛后提取 M*inv 作为最终 CRWM**。

### 2.3 因果自动化奖励设计（Causal-ARD）—— 零样本推理
- **图谱转提示**：对 M*inv 的绝对边绝对值执行 1D 2-means 聚类，以聚类中心中点作为阈值 τ，提取活动因果边，序列化为三元组 (源, 目标, 因果效应)，嵌入到系统提示中形成**因果拓扑提示（Causal Topology Prompt）**。
- **因果修剪（Causal Pruning）**：LLM 在生成奖励代码时，**必须排除**任何没有到 score 节点的因果路径的变量（系数置零），从而消除虚假相关。
- **零样本输出**：对于未见任务，LLM 接收任务描述、观察空间和因果拓扑提示，单次生成可执行 Python 奖励函数，无需环境反馈迭代。

- **URDP**：贝叶斯优化 + LLM 结构细化，样本效率较高但仍需迭代。

1. **零样本性能比较**：14 个训练任务蒸馏 CRWM，6 个未见任务测试 (Kettle, CatchAbreast, CatchOver2Underarm, DoorCloseOutward, Pen, LiftUnderarm)，报告 SR 与 ESI。

3. **跨域泛化**：CRWM（Dexterity 训练）直接应用于 ManiSkill2 三个任务。
4. **真实世界对齐**：3 个真实任务，每任务 25 成功 + 25 失败轨迹，计算 AUC。
5. **失效模式分析**：统计 Eureka/URDP 生成奖励中优化崩溃和规范博弈的频率（20 任务）。

- **偏差风险**：预训练任务来自同一 Dexterity 套件，可能引入领域偏差；跨域泛化到 ManiSkill2 虽然成功，但选取的变量已在组件池内，未测试完全新物理量（如流体）。真实实验只有对齐验证，未做端到端策略部署。

## 6. 主要结论与发现
- CRWM 实现了零样本奖励函数生成，**无需任何反馈迭代**，在 6 个未见 Dexterity 任务上成功率（平均约 0.85）匹敌或超过需要 1-4 轮迭代的 URDP 和 Eureka，而 ZS-LLM 仅约 0.0-0.38。
- **因果结构先验是关键**：消融表明去掉任一组件（先验、EMD、软融合）后 SR 平均下降 0.4-0.5；使用 LLM 自推断拓扑的变体几乎失效（平均 SR 0.09）。
- **跨域泛化能力强**：从 Shadow Hand 迁移到单臂 ManiSkill2，零样本 SR 达 0.64-0.89，显著优于无因果方法。
- **真实世界对齐**：CRWM 奖励对成功/失败轨迹的区分度 AUC ≈ 96.5%，远高于 ZS-LLM 的 53.9%。
- **失效模式缓解**：Eureka 和 URDP 生成的奖励分别有 21.2%/10.4% 和 12.6%/4.7% 发生优化崩溃/规范博弈，CRWM 几乎消除。

## 7. 优点
1. **范式创新**：首次将因果世界模型引入 ARD，实现“一次蒸馏，到处推理”的白盒零样本设计，显著降低新技能获取延迟。
2. **机制设计精巧**：EMD 将稳定因果骨架与状态依赖瞬态分量解耦，既保留可迁移结构，又保证微观轨迹重建精度；置信软融合避免硬约束引入虚假结构。
3. **实验严谨全面**：覆盖零样本、消融、跨域、真实世界、超参数分析、LLM/因果模型替换，消融设计针对核心贡献，对比基线充分。
4. **可解释性**：CRWM 的因果图可可视化，明确展示各变量与任务分数间的因果关系，便于人类审查。
5. **实际可行性**：在真实机器人上验证奖励对齐，朝落地迈进一步。

## 8. 不足与局限
1. **预训练成本高**：需要大量离线策略训练（4200 次运行，约 50 GPU·小时级别），虽然是一次性开销，但对大规模任务扩展仍构成负担。
2. **泛化边界受限**：全局组件池覆盖常见运动学/动力学变量，若新任务涉及池外物理量（如流体、可变形物体），CRWM 无法直接推理，需扩充池并收集对应数据。
3. **双臂真实实验缺失**：未在真实双臂机器人上验证端到端策略，仅用单臂 CASBOT W1 做奖励对齐，双臂场景的 sim-to-real 差距尚未检验。
4. **理论假设简化**：局部线性假设可能不适用于强非线性或接触-碰撞密集的任务；EMD 对瞬态分量的建模能力受 MLP 容量限制。
5. **无端到端 Sim-to-Real 策略**：真实实验仅评估奖励对齐，未部署 RL 策略，奖励函数在实际训练中是否仍鲁棒未知。
6. **消融实验中部分变体性能骤降**（如 CRWM w.o. Prior 从 0.85 降至 0.36），表明方法对粗先验质量有一定敏感性，若因果基础模型估计偏差过大，可能影响最终效果。
