## 摘要
空间泛化对于模仿学习的操作策略至关重要，但通常需要跨越不同物体姿态、机器人配置和相机视角的大量示范数据。从少量源示范中进行数据增强为昂贵的真实世界数据采集提供了一种实用的替代方案。基于仿真的增强可以创建可控的变化，但需要复杂的环境和物体设置，并可能引入仿真到现实的差距。最近的真实到真实方法通过联合编辑来自真实示范的三维观测和动作轨迹来避免这些问题，但它们仍然依赖于强大的三维场景解析和几何补全，并且通常产生针对三维点云策略而非基于RGB的二维策略的观测。我们提出了R2RDreamer，一个真实到真实的示范增强框架，它在保持三维动作-观测编辑的几何一致性的同时，将视觉补全转移到二维视频空间。具体来说，R2RDreamer首先通过在一个共享的三维框架中编辑不完整的物体点云和末端执行器轨迹来执行轻量级的三维增强；然后，它通过具有遮挡感知推理的掩膜图像空间控制视频将编辑后的场景投影，并使用密集控制图像到视频模型补全时间上连贯的RGB观测。在空间偏移的操作任务上，使用二维扩散风格策略和视觉-语言-动作策略进行的实验表明，R2RDreamer从有限的源示范中提高了空间泛化能力，分析验证了三维编辑、遮挡感知投影和视频补全的贡献。

## Abstract
Spatial generalization is critical for imitation-learned manipulation policies, but achieving it typically requires scaling demonstrations across diverse object poses, robot configurations, and camera viewpoints. Data augmentation from a few source demonstrations offers a practical alternative to costly real-world collection. Simulation-based augmentation can create controllable variation, but requires complex environment and object setup and may introduce a sim-to-real gap. Recent real-to-real methods avoid these issues by jointly editing 3D observations and action trajectories from real demonstrations, yet they still rely on strong 3D scene parsing and geometry completion, and often produce observations tailored to 3D pointcloud policies rather than RGB-based 2D policies. We propose R2RDreamer, a real-to-real demonstration augmentation framework that preserves the geometric consistency of 3D action-observation editing while moving visual completion to 2D video space. Specifically, R2RDreamer first performs lightweight 3D augmentation by editing incomplete object pointclouds and end-effector trajectories in a shared 3D frame; it then projects the edited scene into masked image-space control videos with occlusion-aware reasoning and uses a dense-control image-to-video model to complete temporally coherent RGB observations. Experiments on spatially shifted manipulation tasks with both 2D diffusion-style policies and vision-language-action policies show that R2RDreamer improves spatial generalization from limited source demonstrations, with analyses validating the contributions of 3D editing, occlusion-aware projection, and video completion.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：模仿学习的视觉运动策略（如 2D 扩散策略、视觉-语言-动作模型 VLA）在面对物体姿态、机器人配置、相机视角的空间变化时，泛化能力严重不足。为覆盖空间多样性，需要采集大量真实演示，成本高昂。
- **现有方法局限**：
  - **仿真增强**（如 MimicGen）：可生成可控变化，但需仿真资产和环境设置，且存在仿真到真实（sim-to-real）偏差。
  - **真实到真实增强**（如 DemoGen、R2RGen）：直接在真实演示的 3D 空间中编辑观测和动作，但依赖强力的 3D 场景解析与几何补全（如完整点云、模板、6D 跟踪），且产出仅适配 3D 点云策略，无法为 RGB 2D 策略服务。
- **研究动机**：提出一种既能保持 3D 编辑的几何一致性，又能输出高质量 RGB 观测，从而支持 2D 策略（包括 VLA）的空间泛化数据增强框架。

## 2. 论文提出的方法论

### 核心思想
- **三步流水线**：① 轻量级 3D 编辑 → ② 遮挡感知投影生成掩码控制视频 → ③ 稠密控制图像到视频模型补全 RGB 观测。
- **关键原则**：在 3D 共享帧中联合编辑物体点云和末端执行器轨迹，保证动作与观测的几何一致性；但不再要求 3D 场景完整，而是将其作为控制几何，不可靠区域通过 2D 视频补全修复。

### 关键技术细节
1. **轻量级 3D 编辑（3D Co-Editing）**：
   - 使用 SAM2 对 RGB-D 视频进行物体分割和跟踪，提取不完整物体点云。
   - 通过机器人运动学模型重建机器人臂点云。
   - 将演示轨迹划分为技能段（skill）和运动段（motion）。对每个技能段，采样一个变换 \( T_i \) 并应用于相关物体点云和末端位姿：\( \hat{P}^k_t = T_i P^k_t \)，\( \hat{A}^{ee}_t = T_i A^{ee}_t \)。
   - 保留夹爪命令；运动段通过插值或运动规划生成。
   - 无需完整的 3D 重建模型（如 FoundationPose、SAM3D），对刚体、铰接体、可变形物体一视同仁。

2. **遮挡感知投影（Occlusion-Aware Projection）**：
   - 将编辑后的点云投影到目标相机，形成稀疏的控制帧 \( \tilde{C}_t \)。
   - 定义**自遮挡**（self-occlusion）：使用 HPR（Hidden Point Removal）和局部 z-buffer 检测原本可见的点是否因物体旋转后应被隐藏，标记为黑色。
   - 定义**外部遮挡**（external occlusion）：对投影边界多边形膨胀，标记外围区域。
   - 最终掩码 \( Q_t = (\bigcup_k Q^{self,k}_t) \cup Q^{ext}_t \)，控制帧 \( C_t = (1 - Q_t) \odot \tilde{C}_t + Q_t \odot 0 \)，堆叠得到掩码控制视频。

3. **投影控制的视频补全模型**：
   - 基于 WAN2.2 IT2V 模型，添加稠密控制分支输入 \( C_{1:H} \)（与目标视频时空对齐）。
   - 编码为潜变量，与噪声潜变量拼接，通过 DiT 进行流匹配训练。损失函数：
     \[
     L_{fm} = \mathbb{E}_{x_0,x_1,\tau} \left[ \| w(q) \odot (v_\theta([x_\tau; c], \tau, l, r) - (x_1 - x_0)) \|_2^2 \right]
     \]
     其中 \( w(q) = 1 + \lambda (1 - q) \) 对非黑色区域施加更大惩罚，以保护控制像素。
   - 推理时逐块生成，首块仅依赖语言和控制，后续块额外参考上一块的最后一帧以保持时序连贯。
   - 支持推理时混合（从控制视频取非黑像素，生成像素用于掩码区域）。

4. **自监督训练数据构造**：
   - 从普通 RGB 视频构造两种掩码对：
     - **投影一致掩码**：对物体点云应用变换并反向映射，模拟 3D 编辑后的自遮挡和外部遮挡。
     - **随机物体丢弃掩码**：随机丢弃一定比例跟踪到的物体像素。
   - 无需额外标注，即可训练补全模型。

## 7. 优点

- **方法创新**：将视觉修复从困难的 3D 几何补全转移到可扩展的 2D 视频补全，降低了对精确 3D 感知的依赖。
- **实用性**：产出标准 RGB 视频与动作对，可直接训练主流的 2D 策略（包括扩散策略和 VLA），无需修改策略架构。
- **轻量级**：免去模板、6D 跟踪、完整 3D 重建等复杂模块，只需 SAM2 分割/跟踪和机器人模型，降低工程门槛。
- **自监督训练**：视频补全模型可通过构造掩码对自监督训练，无需增广后的 GT 观测。
- **遮挡处理细致**：分别考虑自遮挡和外部遮挡，提高了控制视频的几何保真度。
- **实验验证充分**：在四个不同类型的任务上验证，展示了在非刚性物体上的优势。

## 8. 不足与局限
