## 摘要
长时域任务在真实世界机器人部署中很常见，然而针对此类任务的失败检测仍未得到充分探索。检测长时域机器人任务中的失败尤其具有挑战性，因为失败的开始往往模糊不清，且通常缺乏密集的时间注释。我们提出了Foresight，一种失败检测框架，它利用来自动作条件世界模型的潜在表示来监控操作轨迹。Foresight仅使用最终的任务级成功或失败标签进行训练。通过利用预测性世界模型嵌入，我们的方法为不同策略下的失败检测提供了统一框架。我们进一步使用函数共形预测（FCP）自适应地校准检测阈值。我们在LIBERO-Long、ManiSkill-Long和BEHAVIOR-1K的仿真环境中，使用最先进的视觉-语言-动作策略评估Foresight，并与最先进的失败检测方法进行比较，同时在真实机器人上使用ReactorX-200臂上的三个长时域任务和Franka臂上的一个任务进行验证。我们的结果表明，动作条件世界模型嵌入为长时域操作中的可靠失败监控提供了可扩展的表示。

## Abstract
Long-horizon tasks are common in real-world robotic deployments, yet failure detection for such tasks remains underexplored. Detecting failures in long-horizon robotic tasks is particularly challenging because failure onset is often ambiguous and dense temporal annotations are typically unavailable. We present Foresight, a failure detection framework that monitors manipulation trajectories using latent representations from an action-conditioned world model. Foresight is trained using only final task-level success or failure labels. By leveraging predictive world-model embeddings, our method provides a unified framework for failure detection across different policies. We further use functional conformal prediction (FCP) to calibrate detection thresholds adaptively. We evaluate Foresight with state-of-the-art vision-language-action policies in simulation on LIBERO-Long, ManiSkill-Long, and BEHAVIOR-1K, compare it against state-of-the-artfailure detection methods, and validate it on real robots with three long-horizon tasks on a ReactorX-200 arm and one task on a Franka arm. Our results suggest that action-conditioned world-model embeddings provide a scalable representation for reliable failure monitoring in long-horizon manipulation.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：长时域机器人操作任务（数百至数千步）中的失败检测极具挑战性。由于失败发生时间点模糊、缺乏密集的时间标注，并且同一视觉状态在不同任务阶段含义不同（如物体在桌上可能是抓取前正常状态，也可能是放置后失败状态），现有方法多聚焦短时域或策略内部信号，难以应对长时域任务中微小偏差的累积效应。
- **背景**：真实机器人部署需要实时监控执行轨迹，提前发现偏离成功的迹象。当前方法如 FAIL-Detect、SAFE、RND、Gauge 等各有局限：或依赖策略内部特征（无法跨策略泛化）、或仅处理短时域、或需要像素级重建。

## 2. 方法论
### 核心思想
- 利用**动作条件世界模型**（action-conditioned world model）的潜在表示来监控机器人操作轨迹。世界模型可编码任务相关的状态线索（空间关系、运动模式、交互动力学等），其预测的潜在特征能反映执行是否与预期一致。
- 仅使用**最终任务级成功/失败标签**训练，无需每步标注。
- 结合**功能共形预测**（Functional Conformal Prediction, FCP）自适应校准检测阈值，提供统计保证。

### 关键技术细节
1. **世界模型特征提取**：采用 V-JEPA 2-AC 作为骨干。视觉编码器（ViT-Giant）冻结，动作条件预测器从零训练。给定观察上下文 \(c_t\)（当前帧或历史窗口）和策略预测的动作块 \(A_t\)，得到：
   - 潜在隐藏特征 \(z_{ht} = \text{Pool}(f_\phi(c_t))\)
   - 动作条件预测特征 \(z_{pt} = \text{Pool}(g_\psi(z_{ht}, A_t))\)
   - 最终令牌 \(u_t = W z_{pt} + p_t\)（加位置编码）
2. **失败评分函数**：使用因果 Transformer（或 LSTM、MLP 变体）将历史令牌序列 \(U_{\le t}\) 映射到每步失败分数 \(s_t \in [0,1]\)，因果掩码确保只使用当前及之前信息。训练时每条轨迹继承最终标签，并采用早期检测加权。
3. **阈值校准**：在成功 rollout 的校准集上，用 FCP 构建时变阈值 \(\delta_t = \mu_t + \hat{q}\sigma_t\)，其中 \(\mu_t\) 为平均分数轨迹，\(\sigma_t\) 为时变标准差，\(\hat{q}\) 为校准非一致性分数的 \((1-\alpha)\) 分位数。当 \(s_t \ge \delta_t\) 时触发失败警报。

## 3. 实验设计
### 数据集 / 场景
- **仿真**：三个基准

  - **ManiSkill-Long**：4个长链任务（如堆6个立方体），平均1,484步；评估 π0-FAST。
  - **BEHAVIOR-1K**：4个移动操作任务（如设置捕鼠器），平均8,557步；评估 π0.5 改进版。
- **真实机器人**：

### 对比方法
- **FAIL-Detect**：基于不确定性的OOD检测（仅成功数据）。
- **SAFE**：利用策略内部表示训练失败检测器（MLP或LSTM）。
- **RND**：随机网络蒸馏建模成功 rollout 的嵌入分布。
- **Gauge**：使用压缩视频世界模型潜在表示 + 共形决策函数。
- **Foresight**：使用 MLP、LSTM、Transformer 三种检测头。

- **ROC-AUC**：阈值无关的分离能力，取轨迹最大分数作为汇总。
- **平衡准确率 (Balanced Accuracy)**：阈值依赖性能，对类别不平衡稳健。
- 使用3折交叉验证，校准阈值时扫描 \(\alpha \in [0.02, 0.05, \dots, 0.90]\) 选取最优。

## 8. 不足与局限
- **计算成本高**：世界模型推理约 183 ms（H200），对实时或敏捷任务可能过慢，难以部署到边缘设备。
- **共形预测假设**：保证依赖校准分布与部署分布匹配；若部署时遇到未见过失败模式，阈值可能失效。

- **缺乏理论分析**：未深入解释为何动作条件潜在比隐藏潜在更好，或世界模型可解释性。
- **数据收集成本**：训练世界模型需要大量 rollout 数据（每个基准数百回合），在真实场景中可扩展性存疑。
