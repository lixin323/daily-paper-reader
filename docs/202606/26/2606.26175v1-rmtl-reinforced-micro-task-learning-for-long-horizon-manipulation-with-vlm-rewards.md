## 摘要
用于机器人操作的强化学习通常需要手动设计密集的奖励函数，这难以调整且往往脆弱，或者需要从人类演示或偏好中学习奖励，这成本高昂。最近的一系列工作使用预训练的视觉语言模型（VLM）作为零样本奖励模型，用单个文本提示替代这些成本。然而，我们认为对于初始条件随机的长时程操作任务，单个全局提示过于粗略。单提示VLM奖励在轨迹的大部分区域近乎平坦，使得智能体难以检测早期进展。我们提出强化微任务学习（RMTL），该方法将操作任务分解为一小组由语言描述的微任务，并训练智能体在它们之间切换。每一步，智能体收到使用当前活跃微任务提示计算的多视角VLM奖励，并在多个相机视角上平均以减少视角特定遮挡的影响。反向课程逐渐将智能体暴露于更困难的初始条件，而PPO工作者首先使用一个固定的基于距离的规则来选择活跃微任务。然后我们用学习到的层次管理器替换该规则，将基于规则的阶段选择转变为完全学习的层次策略。我们在Fetch操作环境中实例化RMTL，使用三个短阶段特定提示，无需额外的提示调整。实验表明，RMTL比单提示VLM奖励提供更有信息的奖励信号，从而实现更快速的学习。这些结果表明，将VLM奖励分解为微任务特定的语言提示可以显著提高语言引导强化学习在机器人操作中的可扩展性。

## Abstract
Reinforcement learning (RL) for robotic manipulation often requires manually designing a dense reward function, which is difficult to tune and often fragile, or learning a reward from human demonstrations or preferences, which can be expensive. A recent line of work uses pretrained vision-language models (VLMs) as zero-shot reward models, replacing these costs with a single text prompt. However, we argue that a single global prompt is too coarse for long-horizon manipulation tasks with randomized initial conditions. The single-prompt VLM reward is near-flat for much of the trajectory, making early progress hard for the agent to detect. We propose Reinforced Micro-Task Learning (RMTL), an approach that decomposes a manipulation task into a small set of language-described micro-tasks and trains the agent to switch between them. At each step, the agent receives a multi-view VLM reward computed using the prompt of the currently active micro-task and averaged across multiple camera views to reduce the effect of view-specific occlusions. A reverse curriculum gradually exposes the agent to harder initial conditions, while a PPO worker is first trained with a fixed distance-based rule that selects the active micro-task. We then replace this rule with a learned hierarchical manager, turning rule-based phase selection into a fully learned hierarchical policy. We instantiate RMTL on the Fetch manipulation environment using three short stage-specific prompts and without additional prompt tuning. Experiments show that RMTL provides more informative reward signals than single-prompt VLM rewards, enabling faster learning. These results suggest that decomposing VLM rewards into micro-task-specific language prompts can substantially improve the scalability of language-guided reinforcement learning for robotic manipulation.

## 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
将长时程操作任务分解为 \(K\) 个语言描述的微任务（如“接近”、“对齐”、“抓取”），并在每个时间步根据当前活跃微任务的提示计算多视角VLM奖励的均值。通过反向课程逐步增加初始条件难度，先使用固定规则切换微任务训练PPO工作者，再训练一个学习的分层管理器（hierarchical manager）取代规则，实现完全学习的分层策略。

### 关键技术细节

1. **多视角语义评分聚合**
   - 从 \(V=6\) 个固定视角渲染图像，每个视角独立计算VLM分数，然后取算术平均值作为标量奖励。
   - 使用基于CLIP的投影评分器：定义基线提示 \(b\)（无任务进展）和微任务目标提示 \(\tau_i\)，将文本嵌入差 \(d_i = e_{\tau_i} - e_b\) 作为语义轴，通过投影混合参数 \(\alpha\)（文中取0.9）控制奖励尺度：
     \[
     P_{\alpha}(d_i) = \alpha \frac{d_i d_i^\top}{\|d_i\|_2^2} + (1-\alpha)I
     \]
     每个视角的分数：
     \[
     r_v^{(i)} = 1 - \frac{1}{2} \| (x_v - e_{\tau_i}) P_{\alpha}(d_i) \|_2^2
     \]
     多视角平均：
     \[
     r_t^{(i)} = \frac{1}{V} \sum_{v=1}^V r_v^{(i)}
     \]

2. **微任务提示分解**
   - 使用 \(K=3\) 个微任务提示：
     - **approach**：“一个两指机器夹爪张开在其爪中心上方对准红色方块”
     - **align**：“一个机器夹爪用两指捏住红色方块”
     - **grasp**：“一个机器夹爪提起红色方块”
   - 基线提示：“一个机器夹爪和一个红色方块在桌子上”
   - 每个时间步只计算当前活跃微任务的奖励，而非三个任务的加和或平均。

3. **反向课程**
   - 将初始夹爪和手指姿态分布从“简单”（靠近物体）逐步过渡到“困难”（完全随机工作空间）。
   - 分为5个难度等级，每个等级由在线成功率门控（如达到50%才解锁下一级），保证智能体先在容易场景学会基本行为。

4. **阶段1：基于规则的PPO工作者**
   - 使用固定距离规则选择活跃微任务（如根据夹爪-方块距离分段）。
   - 工作者网络为MLP [256,256]，使用PPO优化，仅接收当前微任务的VLM奖励。
   - 超参数：rollout长度40，batch size 64，学习率3e-4，折扣0.95，GAE λ=0.95。

5. **阶段2：学习层次管理器**
   - 管理器：小MLP [128,128] + softmax，输出K类微任务，每隔 \(H=3\) 步决策一次。
   - 先通过行为克隆（BC）从规则标签预热（250个回合、3500次更新）。
   - 之后使用REINFORCE优化，基于段回报（segment return）的z-score优势：
     \[
     L_M = -\mathbb{E}[\log \pi_M(\phi|s) \cdot A_{seg}] - c_H H[\pi_M] + w_{KL} KL(\pi_{rule} \| \pi_M)
     \]
     其中熵系数 \(c_H=0.01\)，KL权重 \(w_{KL}=0.30\)，探索使用ε-greedy（ε=0.20）。
   - 前50,000环境步冻结工作者actor（仅critic可训练），之后以较低学习率（1e-4）解冻。

### 算法流程（文字说明）
阶段2整体流程：
1. **BC预热**：使用规则选择器在加载的PPO检查点上运行250回合，收集(s, φ_rule)对；训练管理器拟合这些标签。
2. **在线HRL训练**：
   - 每3步管理器采样一次微任务φ。
   - 工作者使用含one-hot微任务的增广状态输出动作。
   - 从多视角VLM获取奖励，累积段回报。
   - 每完成一个rollout（所有并行环境），用PPO更新工作者（初期只更新critic），用REINFORCE更新管理器（基于段回报的z-score优势）。
3. **冻结-解冻调度**：超过50k步后解冻工作者actor并降低学习率。

## 论文主要结论与发现

1. **微任务分解是性能提升的主导因素**：将单全局提示分解为三个阶段特定提示，将平坦的单信号转换为分段单调信号，使PPO能够有效学习（图5）。单提示变体在随机初始条件下完全无法收敛（成功率0%），而RMTL达到89%（非分层PPO）或更高。
2. **多视角聚合减少遮挡噪声**：6视角平均比任何单一视角提供更平滑的奖励轨迹（图8）。
3. **反向课程是必需的**：没有课程时，语言奖励在随机初始化时过于不具信息性，无法启动PPO（图6显示学习进程依赖难度递进）。
4. **学习管理器超越规则**：规则管理器达到94%成功率，学习的管理器进一步提升至98%，且与规则有73%决策一致性，证明规则是好的归纳偏差但并非最优（图7）。
5. **整体方法有效性**：RMTL使语言引导RL在长时程操作中变得可行且高效，证明了微任务分解的可扩展性优势。

## 优点

- **新颖的奖励分解框架**：将单提示VLM奖励拆分为微任务特定提示，产生分段单调、更密集的训练信号，直接缓解了长时域稀疏奖励问题。
- **多视角聚合简单有效**：不引入额外计算复杂度的前提下显著降低遮挡噪声，属于轻量但关键的改进。
- **反向课程结合VLM奖励**：在初始阶段VLM信号不足时，通过课程逐步暴露困难，确保探索能够启动。
- **分层管理器的两阶段训练**：先规则BC预热，后REINFORCE微调，并冻结工作者actor稳定早期训练，设计务实、稳定。
- **实验消融完备**：每个核心组件（分解、多视角、课程、管理器）都通过精确控制变量进行了验证，结果直观、可重复。
- **在Fetch环境上达到98%成功率**，显著优于单提示基线（0%）。

## 不足与局限

- **环境泛化性有限**：仅在单一FetchPickAndPlace任务上测试，未在多种长时操作（如多步装配、移动基座操作）上验证，难以断定方法的一般性。
- **VLM依赖和视觉域限制**：奖励信号受限于VLM的感知能力，需要高保真渲染（鲜艳颜色、木纹等）才能获得合理分数。真实场景中光照、纹理变化可能导致噪声。VLM在接触密集阶段的空间推理能力有限，奖励可能模糊。
- **饱和问题**：抓取提示一旦方块被牢牢抓住，奖励迅速饱和（不再随提升高度变化），丢失梯度。本文通过奖励后处理（如截断-1~0）缓解，但未根本解决。
- **手动设计依然存在**：微任务提示、阶段数量、反向课程参数、规则选择器（阶段1）均需手动设定。论文指出未来可结合LLM自动分解，但目前仍需人工设计。
- **计算资源**：使用单A100、16并行环境，虽不算极高，但VLM推理（每步6视角）可能成为瓶颈，未给出具体时间。
- **未与最先进VLM奖励方法直接对比**：如Eureka（代码生成奖励）、VIP/LIV（学习后置奖励）等。仅与自身消融基线比较，缺乏横向评估。
- **未来方向**：文中提出将规则完全去除并与LLM自动分解结合、扩展更多任务等，暗示当前版本仍有进一步自动化空间。
