## 摘要
移动操控器需要当前、可查询、语义有意义且能在边缘计算约束下使用的世界模型。本技术报告提出KRVF，一种面向边缘移动操控的源感知语义体素世界表示。与主要优化全局几何保真度的以重建为中心的地图管线不同，KRVF将局部世界状态表示为面向任务的体素，编码占用、颜色、语义证据、时间新鲜度和证据来源。该表示将测量的占用与语义先验假设分离，使得在深度失败时仍能进行物体推理，而不会静默地破坏持久几何。KRVF还通过渲染地图先验深度进行修复，闭合了映射与感知之间的反馈循环，并提供了面向任务级别的查询操作符以获取语义物体和抓取候选。本报告形式化定义了KRVF表示，并记录了将在线RGB-D观测转化为面向任务的机器人记忆的ROS 2实现。

## Abstract
Mobile manipulators need world models that are current, queryable, semantically meaningful, and usable under edge-compute constraints. This technical report presents KRVF, a source-aware semantic voxel world representation for edge mobile manipulation. Unlike reconstruction-centric mapping pipelines that primarily optimize global geometric fidelity, KRVF represents local world state as task-oriented voxels that encode occupancy, color, semantic evidence, temporal freshness, and evidence source. The representation separates measured occupancy from semantic-prior hypotheses, enabling depth-failure-aware object reasoning without silently corrupting persistent geometry. KRVF also closes a feedback loop between mapping and sensing by rendering map-prior depth for repair, and exposes task-level query operators for semantic objects and grasp candidates. The report formalizes the KRVF representation and documents a ROS 2 implementation that turns online RGB-D observations into a task-facing robot memory.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：移动操作机器人在边缘计算（Edge Computing）约束下，需要实时、可查询、语义丰富且支持任务执行的世界模型。现有以重建为中心的地图管线（如TSDF、OctoMap等）主要优化全局几何精度，缺乏对任务导向、证据来源、时间新鲜度、深度失败场景的综合表示，导致在操作任务中无法高效回答“物体在哪里”“证据可靠吗”“观测是否最新”“下一步动作是什么”等问题。
- **整体含义**：提出一种**源感知（Source-Aware）语义体素世界表示**——KRVF，将每次观测的来源、置信度、时间戳、语义证据等显式编码到体素状态中，并分离测量占用与语义先验假设，使得机器人能够在深度传感器失败（如透明、反光、暗色物体）时仍进行物体推理，同时保持持久几何的完整性。KRVF还将地图与感知形成闭环（通过渲染地图先验深度修复损坏深度），并提供面向任务级别的物体和抓取查询接口，使下游行为树和操作管线可以直接消费世界状态，而非原始点云。

## 2. 论文提出的方法论

- **核心思想**：将世界表示从“重建导向”转向“任务导向”，体素不仅存储几何占用，还存储色彩、语义证据、观测置信度、时间新鲜度、证据类型（原始深度、修复深度、假设等）。通过**观测-假设分离**，测量得到的占用（`K_obs`）与语义先验假设（`K_hyp`）分为独立图层，防止语义检测物错误地覆盖持久几何。
- **关键技术细节**：
  - **源感知体素状态**：每个体素 `v_i = (l_i, c_i, s_i, q_i, τ_i, η_i)`，分别对应占用对数几率、视觉外观、语义、观测质量/置信度、时间新鲜度、证据类型。
  - **源加权证据融合**：占用更新 `Δl_i = q_t · L_hit(z_t, x_t, v_i)`，其中 `q_t` 为观测来源置信度（原始深度、修复深度、语义假设可具有不同置信度）。
  - **观测-假设分离**：`K_t = K_obs ∪ K_hyp`，且 `K_hyp → K_obs` 必须经过显式确认（如后续有效深度验证）。假设具有生命周期，过期自动清除。
  - **语义门控逆传感器模型**：融合物理观测 `L_phys` 和语义先验 `L_sem`，通过权重 `α_i` 控制。
  - **地图先验深度反馈**：将当前体素地图渲染进相机视图作为深度先验 `ˆz_prior`，结合局部颜色、平面拟合等生成修复深度 `z_repair`，再重新注入地图，实现闭环。
  - **任务级查询**：语义物体查询 `Q_obj(s, x) → O_j`（返回物体ID、标签、边界框、稳定性等），抓取候选查询 `Q_grasp(O_j) → {g_top, g_waist, g_side, g_center}`（基于体素几何启发式排名）。
  - **检测-体素接地**：2D检测标签仅更新已有占用体素的语义，不凭空创建物体；只有在深度缺失时才建立显式假设体素。
- **算法流程**（文字说明）：
  - 输入：同步RGB-D图像、相机标定、TF/位姿变换。
  - 有效深度样本反投影到3D并融合到稀疏分块体素地图中。
  - 每次体素更新包括：占用对数几率（源加权）、颜色（持久与实时）、语义置信度、观测时间戳。
  - 自由空间通过保守射线投射集成；动态清除和过期清理减少陈旧结构。
  - 语义桥节点接收2D检测（如YOLO），采样检测框内深度点，变换后仅更新已有占用体素的语义标签；若深度缺失，生成假设体素。
