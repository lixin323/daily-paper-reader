## 摘要
我们提出了统一运动-动作（UMA）模型，该方法利用3D物体运动轨迹作为共享接口，桥接了视觉运动控制与动力学建模。UMA将物体运动与机器人动作视为在遮蔽生成目标下共同演化的变量，其中遮蔽模式决定了预训练期间的监督机制以及部署时的推理模式。通过使用事后重新标注的运动上下文和对比目标（将任务意图与场景几何解耦），UMA能够在无需人工标注任务指令的情况下，跨异构数据源进行多任务预训练。在部署时，相同的预训练参数支持运动条件化的视觉运动控制、基于运动的动力学建模，以及从少样本演示中进行任务适应。在机器人演示、人类视频和模拟数据的混合数据上进行预训练后，UMA在各个推理模式下均持续优于针对特定任务的最先进基线方法。

## Abstract
We present Unified Motion-Action (UMA) Model, an approach that uses 3D object motion trajectories as a shared interface to bridge visuomotor control and dynamics modeling. UMA treats object motion and robot actions as co-evolving variables under a masked generative objective, in which the mask pattern determines both the supervision regime during pretraining and the inference mode at deployment. Using hindsight-relabeled motion contexts and a contrastive objective that disentangles task intent from scene geometry, UMA enables multi-task pretraining across heterogeneous data sources without requiring manually annotated task instructions. At deployment, the same pretrained parameters support motion-conditioned visuomotor control, motion-based dynamics modeling, and task adaptation from few-shot demonstrations. Pretrained on a mixture of robot demonstrations, human videos, and simulated data, UMA consistently outperforms state-of-the-art baselines specialized for each inference mode.

## 1. 核心问题与整体含义

- **研究动机**：现有机器人学习方法大多依赖同质数据（如机器人演示）和手工任务标注，难以利用异构数据源（如无动作标签的人类视频、模拟数据）进行通用技能学习。视觉-语言-动作模型和世界模型在跨域迁移上表现脆弱，且缺乏统一的物理交互表征。
- **核心问题**：如何设计一个共享接口，使模型能从不同标注程度的数据（动作标注、无动作标注）中联合学习，并支持多种推理模式（动作生成、动力学预测、少样本适应）？
- **整体含义**：UMA 以 3D 物体运动轨迹作为共享接口，将物体运动与机器人动作视为共变变量，通过掩码生成式目标统一建模，从而在异构数据上预训练，无需人工任务指令即可实现多任务学习与泛化。

## 2. 方法论

### 2.1 核心思想
- 将物体运动（3D 点轨迹）与机器人动作视为联合预测的变量，使用 **掩码流匹配（masked flow matching）** 目标训练。
- 通过不同掩码模式切换训练时的监督信号和部署时的推理模式，实现同一模型支持运动条件控制、动作条件运动预测、软提示调优。

### 2.2 关键技术细节
- **任务编码器 hψ**：输入初始观测 o0 和参考运动 xc（稀疏、不规则），输出固定大小的任务潜在变量 c。使用 PointNet++ 提取点云特征，参考运动经时间归一化后交叉注意融合。
- **掩码 DiT 块**：在 DiT 块内设置两套独立的 adaLN 参数，分别作用于目标令牌（需去噪）和条件令牌（保持干净），避免扩散时间步对条件信号的干扰。
- **对比学习损失 Lc**：采用 SimCLR 风格，对同一任务生成多个增强视图（关键点子采样、时间子采样、SE(3) 变换），使 c 对场景几何和参考运动细节不变，只保留抽象任务意图。
- **预训练损失**：L = λx Lx + λa La + λc Lc，其中 Lx 和 La 为流匹配损失，Lc 为对比损失。
- **数据预处理**：从单目 RGB 视频提取 3D 运动轨迹（MegaSaM + UniDepth + SAM3 + TAPIP3D），模拟数据使用随机化动作和状态。

### 2.3 算法流程
- **预训练**：随机掩码运动/动作令牌，联合去噪，所有数据源根据自身标签贡献对应损失。
- **部署**：
  - 运动条件控制：给定目标参考运动，c 由 hψ 生成，预测未来动作。
  - 动力学预测：给定候选动作序列，预测物体运动。
  - 少样本适应：固定模型参数，只优化 c（软提示），在少量演示上进行。

## 6. 主要结论与发现

1. **零样本控制**：UMA 在插入、扫除、折叠任务上分别达到约 85%、80%、75% 的成功率，超过最强基线 COIL 和 UVA 20-25 个百分点。
2. **动力学预测**：UMA 的 MSE 为 0.042，优于 PointWorld 的 0.054；移除模拟数据使 MSE 升至 0.208，凸显模拟数据对运动-动作耦合的关键作用。
3. **少样本适应**：仅 25 个演示、优化任务潜在变量 c，UMA 在动作监督下匹配/超越全模型微调基线；在仅有运动监督（人类视频）下，比 UVA 高约 25 个百分点。
4. **数据贡献**：模拟数据增强运动-动作耦合，人类视频增加任务多样性；两者互补。
5. **对比学习**：移除对比学习后少样本适应成功率下降 30-60 个百分点，表明其对解耦任务意图的关键性。
6. **失败分析**：82% 失败源于执行精度不足（动作执行），18% 源于抓取；说明模型已正确识别任务意图，需更多运动-动作配对数据来提升精度。
7. **缩放性**：增加数据量和模型参数均持续提升性能。

## 7. 优点

1. **统一框架**：用同一模型无缝支持动作生成、动力学预测和少样本适应，无需多个专门模型。
2. **异构数据兼容**：通过掩码机制自然吸收无动作标签数据（人类视频），大幅扩展可学习数据源。
3. **3D 物体运动表示优势**：与动作同坐标系、可从视觉中提取、跨本体/视角可比，优于像素或 2D 表示。
4. **对比学习解耦任务意图**：任务潜在变量 c 对场景几何不变，促进零样本和少样本泛化。
5. **软提示调优高效**：仅优化低维 c 而非更新所有参数，在仅有运动监督时仍有效。
6. **架构设计创新**：掩码 DiT 块双 adaLN 调制，在单次前向传递中区分目标与条件令牌，保持条件信号完整性。
7. **完整的消融与分析**：验证了各组件设计必要性，失败分析指明了未来改进方向。

## 8. 不足与局限

1. **新本体适应性**：部署到新机器人仍需动作头监督（需要兼容动作数据），无法零样本迁移。
2. **相机标定依赖**：所有表示在每集相机坐标系中，机器人动作需校准相机到基座的变换。
3. **单步观测输入**：当前仅使用单步视觉观测，未利用多步历史或跨帧点对应关系。
4. **任务规范局限**：主要依赖参考运动，虽然可扩展至语言和图像，但需额外编码器；语言指令未作为核心消融。
5. **实验覆盖有限**：真实任务仅 3 类（插入、工具、变形），缺乏复杂长时任务（如装配、多步操作）或动态场景验证。
6. **数据偏差风险**：预训练数据主要来自 DROID、HOI4D、Xperience，可能偏向特定场景和物体类别；模拟数据使用启发式动作，与真实分布存在差距。
7. **失败集中于执行精度**：表明运动-动作耦合仍需大规模配对数据，当前模拟数据虽有帮助但仍不足。
