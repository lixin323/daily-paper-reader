## 摘要
现实世界中的鲁棒机器人操作不仅需要理解当前观察，还需要记忆和动力学建模。世界动作模型（WAM）通过联合建模视觉预见和基于当前及历史观察的条件动作来具备这些能力，使其成为机器人操作的一种有前途的范式。然而，现有的WAM面临一个基本权衡：高效推理的方法通常仅以最近的有限观察窗口为条件，因此在非马尔可夫环境中表现不佳；而保留长历史的方法则会产生随序列长度大幅增长的时间和空间成本。为了解决这一挑战，我们引入了MemoryWAM，一种具有高效持久内存的世界动作模型。MemoryWAM采用混合内存设计，结合了最近的帧、事件边界锚定帧以及总结长程历史的紧凑要点标记。一种定制的注意力机制使得能够检索详细的短期上下文和压缩的长期上下文，支持依赖于内存的决策制定，同时降低推理延迟和GPU内存使用。在模拟和现实世界中的长期、依赖于内存的操作任务中，MemoryWAM在保持有利计算效率的同时，优于强视觉-语言-动作（VLA）和WAM基线。

## Abstract
Robust robotic manipulation in the real world requires not only an understanding of the current observation, but also memory and dynamics modeling. World action models (WAMs) possess these capabilities by jointly modeling visual foresight and actions conditioned on both current and historical observations, making them a promising paradigm for robotic manipulation. However, existing WAMs face a fundamental trade-off: methods with efficient inference typically condition only on a bounded window of recent observations and therefore struggle in non-Markovian environments, whereas methods that preserve long histories incur time and space costs that grow substantially with sequence length. To address this challenge, we introduce MemoryWAM, a world action model with efficient persistent memory. MemoryWAM uses a hybrid memory design that combines recent frames, event-boundary anchor frames, and compact gist tokens that summarize long-range history. A tailored attention mechanism enables retrieval of both detailed short-term context and compressed long-term context, supporting memory-dependent decision-making with reduced inference latency and GPU memory usage. Across long-horizon, memory-dependent manipulation tasks in both simulation and the real world, MemoryWAM outperforms strong vision-language-action (VLA) and WAM baselines while maintaining favorable computational efficiency.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：现实世界的机器人操作任务不仅需要理解当前观测，还需要记忆和动力学建模。现有方法中，视觉-语言-动作模型（VLA）学习从当前观测到动作的直接映射，缺乏历史记忆和对物理世界动态演化的建模。世界动作模型（WAM）通过联合建模视觉预见（visual foresight）和动作预测来弥补这一缺陷，成为一种有前途的范式。
- **核心问题**：现有WAM面临一个根本性权衡——高效推理的方法通常仅依赖有限长度的滑动窗口（如Cosmos Policy、FastWAM等），在非马尔可夫环境中任务相关信息可能落在窗口外，导致性能下降；而保留完整历史缓存的WAM（如LingBot-VA、DreamZero）虽然保留了丰富的时序上下文，但推理延迟和GPU内存消耗随轨迹长度线性增长，难以扩展到长程任务。
- **动机**：受人类认知系统启发（短期记忆、长期记忆的“要点痕迹”、事件边界记忆），设计一种高效的混合记忆机制，使WAM在保持持久上下文的同时，显著降低计算开销。

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：提出**MemoryWAM**，一种具有高效持久内存的世界动作模型。采用**混合记忆设计**，融合三个互补成分：
  1. **短期记忆**：滑动窗口缓存最近的 \(N_{\text{recent}}\) 个视频帧的完整视觉token，用于高保真局部上下文。
  2. **事件边界锚帧**：保留任务起始时刻的初始帧（\(N_{\text{init}}\)个锚帧）的完整视觉token，因为初始场景状态常包含关键指令信息。
  3. **要点记忆**：对每个历史帧附加 \(M\) 个可学习的要点标记（gist tokens），这些标记通过注意力机制压缩帧内容。对于既不是锚帧也不是近期帧的帧，后续计算只保留其要点标记的KV缓存，而丢弃原视觉token的KV缓存，实现长程历史的紧凑表示。

- **关键技术细节**：
  - 模型采用**混合Transformer（MoT）架构**：视频分支使用视频扩散Transformer（DiT），动作分支使用独立的动作DiT。训练时通过视频预测提供密集的动力学监督，推理时无需视频去噪，仅通过一次前向传播更新视频侧KV缓存，然后动作DiT在缓存上条件去噪产生动作块。
  - **注意力机制**：动作DiT在生成动作时，同时关注混合记忆中的所有部分（短期窗口、锚帧、要点标记）。注意力掩码设计确保视频帧和动作token只能访问历史上下文，而不访问未来信息。
  - **压缩比**：每帧视觉token数 \(L = 120\)，要点标记数 \(M = 8\)，压缩比 \(d = L/M = 15\)。长程缓存大小从 \(O(NL)\) 降为 \(O(NL/d)\)，存储和注意力成本降低15倍。
  - **动作预测**：动作块长度 \(h=16\)（通过帧步长4和时间VAE步长4实现），每个潜在帧对应一个16步动作块。
  - **训练设置**：采用连续流匹配（flow-matching），1000个训练步；视频和动作分支分别使用不同的噪声调度；自回归地构建每帧的交错干净/噪声视频token序列，应用混合记忆注意力掩码，使训练时的可见性与推理时KV缓存一致。
  - **推理协议**：维护每个Transformer块的混合记忆KV缓存（锚帧、最近4帧、所有历史帧的8个要点标记）。执行动作块后，新观测经VAE编码并预填充到缓存中；动作分支执行50步（仿真）或10步（真实世界）的去噪。

- **效率-性能权衡突破**：MemoryWAM在保持持久上下文的同时，将推理延迟和GPU内存从 \(O(N)\) 降低为 \(O(N/d)\)，且实际效率优于全注意力、TTT、RNN机制（即使在长序列下也更快更省内存）。
