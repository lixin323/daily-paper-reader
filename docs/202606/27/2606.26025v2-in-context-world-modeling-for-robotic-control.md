## 摘要
现代视觉-语言-动作（VLA）模型通常难以泛化到新的设置（例如改变摄像机视角或机器人形态），因为它们通常仅以当前观察和语言指令为条件。通过忽略潜在的系统配置作为变量，这些模型隐含地假设了训练过程中遇到的固定执行环境，从而需要对任何新环境进行数据密集型微调。在这项工作中，我们引入了上下文世界建模（ICWM），这是一个将系统辨识视为上下文自适应问题的框架。ICWM使机器人策略能够从自生成、任务无关的短暂交互历史中自主推断关键系统变量。与使用示范来指定执行何种任务的传统上下文学习不同，ICWM利用上下文窗口来理解系统如何运作。通过在任务执行前处理这些交互，该模型隐式地捕获了当前系统的世界动态，从而无需参数更新即可适应新的配置。在仿真和真实世界机器人平台上的大量实验表明，ICWM在新型摄像机视角下显著优于标准VLA基线。

## Abstract
Modern Vision-Language-Action (VLA) models often fail to generalize to novel setups, such as altered camera viewpoints or robot morphologies, because they are typically conditioned only on current observations and language instructions. By ignoring the underlying system configuration as a variable, these models implicitly assume a fixed execution context encountered during training, necessitating data-intensive fine-tuning for any new environment. In this work, we introduce In-Context World Modeling (ICWM), a framework that treats system identification as an in-context adaptation problem. ICWM enables robot policies to autonomously infer essential system variables from a short history of self-generated, task-agnostic interactions. Unlike traditional In-Context Learning that uses demonstrations to specify what task to perform, ICWM leverages the context window to understand how the system operates. By processing these interactions before task execution, the model implicitly captures the world dynamics of the current system, enabling adaptation to novel configurations without parameter updates. Extensive experiments in simulation and on real-world robot platforms demonstrate that ICWM significantly outperforms standard VLA baselines on novel camera viewpoints.

## 2. 方法论

### 2.1 核心思想

- **ICWM（In‑Context World Modeling）**：将系统辨识转化为上下文适应问题。机器人先执行一段**任务无关的随机探索动作**，记录观察‑动作‑观察转换对 `(o_s^i, a^i, o_e^i)` 作为交互上下文 `T`。此后在执行任务时，策略 `π_θ(a_t | Ψ(T), o_t, l)` 隐式利用 `T` 来恢复当前系统配置 ψ，无需任何参数更新或任务特定示范。

### 2.2 技术细节

- **表示学习**：使用一个共享参数的函数 Ψ(T) 从交互上下文中提取隐式世界模型。Ψ 与 VLA 骨干共享参数，训练时与动作预测联合优化。
- **训练方式**：在每个训练样本前拼接 N 组任务无关交互片段（随机从训练数据池中采样），迫使模型根据上下文变化调整动作预测，从而学习隐含世界动态。
- **测试流程**：
    1. **主动探测阶段**：机器人随机采样目标位姿，执行短随机动作（N=5 或更多），记录视觉转换。
    2. **上下文执行阶段**：将探测到的上下文与当前观测和指令一起送入模型，生成动作。由于 Ψ 与骨干共享参数，整个过程为一次前向传播。
- **推理加速**：可在固定配置下将上下文隐状态通过 KV 缓存预计算，减少每步开销。

### 2.3 理论支撑

基于部分可观测马尔可夫决策过程（POMDP），证明交互上下文 T 比单帧观测携带关于 ψ 的信息量严格更多（Proposition 1）。

## 6. 主要结论与发现

1. **ICWM 显著提升 OOD 视角泛化**：在 LIBERO 上平均 OOD 成功率提升 13.0%（vs. MV）；真实机器人上提升 71%（平均从 17% 到 29%）。

3. **长时任务收益最大**：LIBERO‑Long 上 ICWM 比 MV 高出 26.3%（OOD），因长时任务会放大空间误差。
4. **错误上下文会误导模型**：给定 180°偏移的上下文，性能比无上下文还差（‑24.4%），证明模型真正在利用上下文内容而非仅格式。
5. **探测策略不敏感但需要多样性**：所有四种随机策略均优于基线，但组合最优。
6. **ICWM 可泛化到语义和形态变化**：面对干扰物体、纹理变化、夹爪垫片、连杆长度改变，ICWM 均保持增益，形态上的增益随偏移增大而增大。
7. **隐式表示可辨识**：t‑SNE 显示不同视角的 Ψ(T) 形成清晰聚类，证明模型学到了可区分的世界模型。

## 7. 优点

- **零参数自适应**：无需梯度更新、无需任务示范、无需预校准，仅需短时随机探索。
- **简单有效**：在标准 VLA 骨干上仅修改输入格式（前置交互上下文），即带来显著提升。
- **理论基础扎实**：提出信息论分析证明交互上下文的信息增益。
- **广泛验证**：仿真 + 真实、多种 OOD 设置（视角、语义、形态），消融充分。
- **可解释的隐式表示**：可视化证实 Ψ(T) 确实编码了系统配置。
- **低延迟开销**：通过 KV 缓存可将推理成本降到接近基线。

## 8. 不足与局限

- **真实实验范围有限**：仅用了 UR5e 一种机器人，4 个任务；形态变化仅为简单刚体加长和连杆缩放，未涉及手臂自由度改变或柔性变形。
- **某些 OOD 视角仍困难**：如 135° 视角下所有方法（包括 ICWM）成功率都很低，可能因遮挡或视野丢失。
- **探测阶段安全假设**：随机探索要求工作空间内无任务物体，若在复杂场景中摆放物体可能干扰；虽可设计避免区域，但实际部署需额外安全约束。
- **探测时间开销**：约 5–6 秒一次，虽然可单次执行多次任务，但对单次短任务可能影响体验。
- **未与其他自适应方法（如在线微调）对比**：未与梯度类元学习、快速微调等方法直接比较。
- **数据依赖**：训练需要多配置数据（多视角 / 多形态），若训练数据中配置多样性不足，ICWM 可能学不会泛化。
- **缺乏更复杂的硬件实验**：未在移动平台、灵巧手、双臂机器人上验证。
