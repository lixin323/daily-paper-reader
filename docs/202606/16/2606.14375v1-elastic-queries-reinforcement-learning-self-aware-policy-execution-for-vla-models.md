## 摘要
视觉-语言-动作（VLA）模型是机器人操作中强大的动作生成器，但它们通常以固定的推理和重新规划调度执行。这种刚性忽略了机器人控制的不均匀难度：接触密集或不确定的状态可能需要更多的计算和更新的反馈，而较容易的状态通常可以用较少的推理步骤和更长的开环执行来处理。我们提出弹性查询强化学习（EQRL），一个使每个VLA策略查询具有弹性的框架。一个轻量级的潜在调度适配器联合选择潜在输入、去噪预算和动作块长度，而无需微调底层VLA模型。为了使调度具有难度感知，EQRL在联合潜在-调度动作上训练一个评论家，并从评论家集成的分歧中推导出状态难度信号。该信号将计算引导向困难状态，而学习到的残差允许任务驱动的修正。我们将可变块执行公式化为查询级宏动作强化学习，具有依赖于块的折扣和摊销的功能评估次数（NFE）预算。在仿真和真实机器人操作中，EQRL在保持或提高任务成功率的同时降低了摊销推理成本。

## Abstract
Vision-language-action (VLA) models are powerful action generators for robot manipulation, but they are typically executed with fixed inference and replanning schedules. This rigidity ignores the uneven difficulty of robot control: contact-rich or uncertain states may need more computation and fresher feedback, while easier states can often be handled with fewer inference steps and longer open-loop execution. We propose Elastic Queries Reinforcement Learning (EQRL), a framework that makes each VLA policy query elastic. A lightweight latent-schedule adaptor jointly selects the latent input, denoising budget, and action chunk length, without fine-tuning the underlying VLA model. To make scheduling difficulty-aware, EQRL trains a critic over the joint latent-schedule action and derives a state difficulty signal from critic ensemble disagreement. This signal guides compute toward difficult states, while a learned residual allows task-driven correction. We formulate variable chunk execution as query-level macro-action RL with chunk-dependent discounting and an amortized number-of-function-evaluations (NFE) budget. Across simulation and real-robot manipulation, EQRL reduces amortized inference cost while preserving or improving task success.

- **核心问题**：现有的视觉-语言-动作（VLA）模型在机器人操作中通常采用**固定的推理和重规划调度**（如固定的去噪步数、固定的动作块长度）。这种刚性调度无法适应机器人控制任务的**难度不均匀性**：接触密集、需要精确对齐或不确定的状态需要更多计算和更频繁的反馈，而简单状态（如自由空间移动）可以用更少的推理步骤和更长的开环执行来处理。固定调度在困难状态下计算不足、在容易状态下浪费计算，导致效率低下甚至性能下降。
- **研究动机**：希望让VLA策略的每次查询都能**根据状态难度弹性选择计算预算**（去噪步数）和承诺长度（动作块长度），在不微调底层VLA模型的前提下实现**自感知的策略执行**，在保证或提升任务成功率的同时降低总推理成本。
- **整体含义**：将VLA执行问题重新定义为**状态相关的资源分配问题**，通过强化学习自适应地分配计算资源，是向更高效、更智能的机器人控制迈进的尝试。

## 2. 方法论

### 2.1 核心思想
- 在**冻结的VLA模型**（基于流匹配的动作生成器，如π₀）之上，训练一个**轻量级神经网络适配器**。适配器在每次查询时联合输出**三部分决策**：
  - **潜在引导变量 w**：控制生成哪个动作轨迹（行为选择）。
  - **去噪步数 K**：控制生成动作时消耗的计算量。
  - **执行块长度 C**：控制生成的多少个动作被连续执行（即开环执行时长）。
- 利用**评论家（critic）集成的不确定性**推导出**状态难度信号**，指导调度先验：困难状态分配更多去噪步数和更短动作块，简单状态相反。同时保留**可学习的残差**以便任务特定修正。
- 将**变长块执行**建模为**查询级宏动作强化学习**，使用**依赖于块的折扣因子**（γ^L，L为实际执行的低级动作数）和**摊销的NFE（函数评估次数）预算**。

### 2.2 关键技术细节

1. **潜在调度联合动作**：适配器观察当前状态o，采样三部分：
   - w：潜在引导
   - zK, zC ∈ [-1,1]：连续调度变量，映射为去噪步数和块长的偏差ΔK, ΔC。
   
2. **难度引导调度先验**：
   - 训练一个**critic集成** {Q^{(i)}_ψ(o, \tilde{u})}，其中 \(\tilde{u}=[w, \bar{K}, \bar{C}]\)。
   - 在基调度(K₀, C₀)下评估各评论家的输出，计算其标准差 \(q_{std}(o)\)，归一化得到难度分数d(o)。
   - 转换为**有符号难度** \(s(o) = \tanh(\tau \cdot \text{rank}(d(o)))\)，正表示困难，负表示容易。
   - 根据s(o)调整基调度得到**调度先验** K_p(o) 和 C_p(o)。
   - 最终连续调度 = 调度先验 + 学习残差（乘以门控系数g和控制参数λ_r）。

3. **查询级宏动作RL**：
   - 每执行一个动作块C_j，产生宏转移 (o, \tilde{u}, R, o', L, d)。奖励R由**任务成功奖励**（仅在成功终局给予）+ **统一分发的NFE成本惩罚**构成。
   - Bellman目标：\(y = R + \gamma^L (1-d) \bar{Q}_{targ}(o', \tilde{u}')\)，其中折扣取决于实际执行的步数L。
   - 使用**SAC框架**优化actor（最大化熵+Q值）和critic（最小化Bellman误差）。

4. **辅助损失**：
   - **计算对齐损失**：鼓励调度分配a_alloc（结合归一化K和C）与难度信号s(o)同号。
   - **NFE带惩罚**：设置每个episode的摊销NFE上下界，超预算或过度节省均施加成本，实现全局计算预算控制。

5. **关键公式**（文字说明）：
   - 难度信号：\(s(o) = \tanh(\tau \cdot (2\cdot\text{rank}(q_{std}(o)) - 1))\)
   - 调度先验：K_p = K₀ + 正号偏移或负号偏移；C_p = C₀ - 正号偏移或负号偏移（困难时K↑、C↓）。
   - 最终调度：\(\hat{K} = K_p + \lambda_r g \Delta K\)，\(\hat{C} = C_p + \lambda_r g \Delta C\)，然后裁剪取整。
   - 奖励：\(R_j = b_{ep} + \mathbb{1}[j=N_{ep}]\mathbb{1}[success]\)，其中\(b_{ep} = -\lambda_{cost} \frac{P_{ep}}{N_{ep}}\)，P_ep来自NFE带惩罚。

## 6. 主要结论与发现

1. **性能与效率双赢**：EQRL在LIBERO-4Tasks上相比最佳基线（DSRL）成功率提升+0.01，AUC提升+0.04，相对NFE降低24.3%；在ALOHA-Cube上成功率达到1.00（比DSRL高0.06），NFE降低20.0%。
2. **真实机器人适用**：离线平均成功率0.838（比DSRL高0.025），平均NFE降低32.4%，平均执行时间降低16.1%；在线实验成功率0.95（比DSRL高0.05），NFE降低31.8%。
3. **消融验证必要性**：只降低平均NFE（匹配NFE的DSRL）或只调整步数或只调整块长均不如联合调度，证明**难度感知的联合弹性调度**是性能提升关键。
4. **计算分配可视化**：在真实机器人倒水任务中，EQRL在接触/对齐阶段分配更多NFE，在平稳运动阶段减少NFE，符合预期。
