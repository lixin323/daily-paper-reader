## 摘要
视觉-语言-行动模型（VLA）在机器人操作中展现了强大的任务理解与泛化能力，然而全模型推理的高计算成本限制了其在低延迟、高频率闭环控制中的部署。我们提出了一种异步语义-行动解耦框架，该框架沿现有VLA的内部语义-行动接口将语义理解与行动生成分离，无需重新设计视觉-语言骨干网络或引入外部规划器。一个低频理解模块异步更新可复用的语义条件，而一个高频行动模块持续输出控制动作，无需重复调用完整模型。为缓解旧语义与当前执行状态之间的时间不匹配，我们进一步引入了历史行动条件化与时间错位训练，这些方法提供了短时域执行上下文，并改善了在旧语义条件下的反馈控制鲁棒性。在LIBERO上使用π0.5和UniVLA进行的实验，以及使用UniVLA进行的真实机器人部署表明，所提出的框架实现了高达35.6Hz的服务端行动模块推理吞吐量，并提供了一条低侵入路径，可在不按控制速率运行完整VLA推理的情况下实现高频率闭环控制。

## Abstract
Vision-Language-Action models (VLAs) have demonstrated strong task understanding and generalization in robotic manipulation, yet the high computational cost of full-model inference limits their deployment in low-latency, high-frequency closed-loop control. We propose an asynchronous semantic-action decoupling framework that separates semantic understanding from action generation along the internal semantic-action interface of existing VLAs, without redesigning the vision-language backbone or introducing an external planner. A low-frequency understanding module asynchronously updates reusable semantic conditions, while a high-frequency action module continuously outputs control actions without repeatedly invoking the full model. To mitigate the temporal mismatch between stale semantics and the current execution state, we further introduce historical action conditioning and time-misalignment training, which provide short-horizon execution context and improve feedback control robustness under stale semantic conditions. Experiments on LIBERO with $π_{0.5}$ and UniVLA, together with real-robot deployment using UniVLA, show that the proposed framework achieves up to 35.6 Hz server-side action-module inference throughput and offers a low-intrusion path to high-frequency closed-loop control without running full VLA inference at control rate.

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：视觉-语言-行动模型（VLA）在机器人操作中具备强大的任务理解与跨场景泛化能力，但全模型推理的计算成本极高，导致推理延迟大，难以满足真实机器人控制所需的高频率（如20 Hz）闭环控制。
- **核心问题**：现有VLA通常采用动作分块（action chunking）来缓解推理频率与控制频率的不匹配，但语义理解与行动生成仍存在同步耦合，导致执行过程中语义长时间不变、环境变化时行动滞后。
- **目标**：提出一种低侵入性的方法，在不重新设计VLA骨干、不引入外部规划器的情况下，实现高频闭环控制，同时保持任务成功率和鲁棒性。

## 2. 方法论

### 核心思想
- 将VLA内部沿语义-行动接口拆分为两个异步执行模块：
  - **低频理解模块**：处理视觉观察和语言指令，更新可复用的中间语义条件（如最后层隐藏状态或KV缓存）。
  - **高频行动模块**：基于最新缓存的语义条件、当前机器人状态和近期行动历史，连续生成控制动作，无需运行完整VLA。
- 关键挑战：缓存的语义随执行时间变旧，导致与当前状态不匹配。为此提出两种增强机制：历史行动条件化（注入近期执行历史）、时间错位训练（训练时模拟语义延迟）。

### 关键技术细节
- **解耦接口**：
  - 对于UniVLA：复用最后层隐藏状态（视觉和附加输出token）。
  - 对于π₀.₅：复用完整的视觉-语言条件前缀KV缓存。
- **历史行动注入**：
  - 行动模块接收最近m步执行动作的历史窗口 h_t = [a_{t-m}, ..., a_{t-1}]。
  - UniVLA：通过轻量投影层注入行动生成侧。
  - π₀.₅：作为额外条件嵌入到流匹配行动头。
- **时间错位训练**：
  - 训练时，对每一步t，随机选取延迟Δ ∼ Uniform{0,…,H-1}（H为动作块长度），使用旧语义z_{t-Δ}代替同步语义z_t。
  - 损失函数：L = E_{t,Δ}[ℓ_base(G_φ(z_{t-Δ}, s_t, h_t), A_t)]，ℓ_base继承原始VLA训练目标（token预测/流匹配/行动回归）。
- **推理流程**：
  - 理解模块以约3-5 Hz低频异步更新语义缓存。
  - 行动模块在每个控制步（20 Hz）基于最新缓存语义、当前状态和历史行动重规划完整动作块，然后采用ACT风格的时序集成（指数衰减加权，系数0.1）合并重叠预测，输出最终执行动作。
- **训练细节**：
  - 历史行动在训练时从真实轨迹中提取，并加入小高斯噪声模拟执行偏差。
  - 推理时历史行动来自实际执行的闭环轨迹。

- 异步语义-动作解耦框架能在保持任务成功率的同时，显著提升行动模块推理吞吐量（UniVLA从3.4 Hz提升至35.6 Hz）。

## 7. 优点

- **低侵入性**：无需修改VLA骨干网络或引入外部规划器，仅沿内部语义-行动接口进行解耦，修改局限在行动生成侧。
- **通用性**：在两种代表性VLA（π₀.5和UniVLA）上验证成功，方法能适配不同架构（全微调 vs LoRA+专家训练）。
- **实用性强**：在真实机器人上验证了高频闭环控制的有效性，吞吐量提升显著（10倍以上）。
- **消融分析清晰**：明确区分了纯缓存重用、历史行动、延迟训练各自贡献，验证了方法的合理性。
- **训练简单**：无需多阶段或复杂训练流程，继承原VLA训练目标即可，时间错位采样简单高效。

## 8. 不足与局限

- **依赖内部接口**：框架的可复用性受限于VLA是否存在中间语义条件（如最后层隐藏状态或KV缓存），并非所有VLA都易于分离。
- **旧语义极限**：当语义缓存老化过大或环境发生剧烈变化时，行动模块仍可能受误导。当前采用固定刷新频率（3-5 Hz），不能动态适应场景变化。
- **实验范围有限**：
  - 仅在单臂操作任务上验证，未涉及快速动态操作、移动操作、复杂接触交互。
  - π₀.5异步变体在真实机器人上未部署，缺少端到端闭环验证。
  - 消融仅在LIBERO-Long上，且仅对UniVLA进行了消融，未在π₀.5上验证。
