In this report, we present Hy-Embodied-0.5-VLA, abbreviated as HyVLA-0.5, an end-to-end system that spans the full robot learning stack: data collection, model design, continued pre-training and supervised fine-tuning, RL post-training, and real-world deployment. # 论文详细总结

## 1. 核心问题与整体含义

- **研究动机**：现有 Vision-Language-Action (VLA) 模型多聚焦单一模型或单一环节，缺乏从数据收集到真实部署的完整机器人学习栈。机器人的通用化不能仅靠一个孤立模型实现，必须依赖全栈协同设计（数据、模型、训练、部署）。
- **核心问题**：如何构建一个可落地的端到端系统，解决以下瓶颈：
  - 数据收集：传统遥操作缺乏触觉反馈，手执 UMI 设备精度不足（SLAM 抖动）。
  - 模型设计：通用 VLM 缺乏对机器人控制的专门优化，动作离散化限制控制频率与精度。
  - 训练范式：模仿学习无法达到最后一步灵巧，强化学习依赖脆弱奖励模型。
  - 部署实时性：高容量模型难以满足高频闭环控制要求。

- **整体含义**：提出 **Hy-Embodied-0.5-VLA (HyVLA-0.5)** 作为覆盖全栈的示例系统，证明“完整学习栈”的必要性与可行性，为通用机器人部署提供参考框架。

## 2. 方法论

### 核心思想
- 将 VLA 视为一个完整系统，而非孤立模型。每个组件（数据、表示、策略优化、执行）为特定瓶颈而设计，并共享同一目标：保持稳定的策略接口，同时将具体形态差异吸收到核心之外。

### 关键技术细节

#### 2.1 数据收集：定制指尖 UMI + 动捕笼
- 设备：基于工业夹爪（Changingtek CTAG2F90）改装，指尖附着力传感器，通过外置光学动捕系统（Optical Motion Capture）以亚毫米精度追踪 6-DoF 位姿，替代传统 SLAM。
- 特点：第一人称头戴视角、指尖直接驱动（而非触发机构）、力反馈保留。
- 数据规模：>10,000 小时（1M+ 片段，70 个任务），按场景分为 6 个任务族（洗衣房 28.5%、厨房 19.2% 等）。

#### 2.2 模型架构
- **背板**：Hy-Embodied-0.5-MoT（4B 参数），采用 Mixture-of-Transformers (MoT) 结构，拥有视觉/语言非共享 QKV 与 FFN，跨模态仅通过共享自注意力交互。支持原生分辨率图像编码（Hy-ViT 2.0）。
- **动作专家**：采用条件流匹配（conditional flow matching）生成连续动作块，与 VLM 背板构成双塔路由。动作专家使用 block-wise causal attention（感知块→状态块→噪声动作块）。
- **紧凑记忆编码器**：在 ViT 中插入时间-空间分解注意力（每 4 层一次时间因果注意力），压缩多帧历史视觉 token，减少 VLM 输入视觉 token 数（保留当前帧 token 数）。参数复用原始 ViT 的 QKV 和 WO 投影，无新增可学习参数。
- **Delta-chunk 动作表示**：预测连续步骤间的末端执行器增量动作（相对位姿 + 夹爪命令），解耦策略学习与具体运动学。动作空间为每臂 10 维（3D 位置 + 6D 旋转 + 1D 夹爪），输出动作块大小 H=50。

#### 2.3 预训练与监督微调
- **预训练**：在 Hy-UMI-10K 上训练 200K 步，batch size 1024，学习率 5e-5，AdamW，bfloat16。使用 K=1（单帧）。
- **监督微调 (SFT)**：两个轨道：
  - **Track-A (同体适应)**：在目标机器人上遥操作收集演示，微调并部署到同一机器人（Dobot X-Trainer）。
  - **Track-B (跨体转移)**：仅用 UMI 演示微调，部署到形态不同的机器人（JAKA K1, Astribot S1），无需目标机器人遥操作。
  设置 K=6（含历史帧），H=50，训练 60K 步。

#### 2.4 强化学习后训练：FlowPRO
- 设计原则：直接利用失败样本（P1）、无需奖励/价值模型（P2）、通过近端正则化锚定隐式奖励（P3）。
- **算法**：基于 Proximalized Preference Optimization (PRO) 的离线 RL 算法。
  - 使用流匹配损失作为负对数似然代理：ℓθ(s,a) = E[∥vθ(at,t|s) - (ϵ - a)∥²]。
  - 隐式奖励：rθ(s,a) = β/2 (ℓref - ℓθ)。
  - **RPRO 损失**：LPRO = -E[ log σ(rθ(s,aw) - rθ(s,al)) + ½∑_{a∈{aw,al}} (log σ(rθ(s,a)) + log σ(-rθ(s,a))) ]。
  - 结合监督项：LRPRO = λPRO LPRO + λSFT LSFT。
- **数据采集**：干预-回滚管道，从当前状态回退到之前状态，记录执行片段为负轨迹，遥操作修正为正轨迹。使用平滑插值生成稠密偏好对。迭代 3 轮，每轮 25K 步。

#### 2.5 部署
- **形态无关映射**：相对位姿叠加当前末端位姿得到世界坐标系目标，使用逆运动学求解。固定基机械臂直接有世界系；人形机器人（Astribot S1）使用启发式算法推断底盘与躯干姿态。
- **异步执行**：推理线程与执行线程解耦，通过线程安全缓冲区覆盖，隐藏主干延迟。
- **贝塞尔块拼接**：使用三次 Bézier 曲线 C1 连续连接新旧动作块，根据历史运动方向和未来块局部方向设置控制点，参数 α、γ、σ 控制截断与平滑程度。

## 6. 主要结论与发现

1. **HyVLA-0.5 在模拟基准上达到 SOTA**：RoboTwin 2.0 上 Clean 90.9%、Randomized 90.1%，超过所有对比方法（包括 π0 和 π0.5）。
2. **UMI 预训练显著提升真实机器人性能**：特别是在精度要求高的子步骤（如折叠、拉链插入），预训练改善了关键时刻的动作分布。
3. **跨体转移可行**：仅用 UMI 数据微调即可部署至不同形态机器人（JAKA K1, Astribot S1），成功率显著高于未预训练基线。
4. **FlowPRO 后训练进一步逼近天花板**：相比 DAgger 和 π0.6*，RPRO 获得更高成功率与更短完成时间，且无需奖励模型。
5. **力模态可行性验证**：在 Unitree G1 上，利用指尖力传感器实现力判别任务，证明 UMI 数据蕴含丰富触觉信息。
6. **各组件贡献**：消融实验表明紧凑记忆编码器与 UMI 预训练均带来增量收益。

## 7. 优点

- **全栈联合设计**：数据→模型→训练→部署统一考虑，而非孤立优化。各组件相互配合（如 delta-chunk 便于跨体映射、UMI 数据同时用于预训练与 RL 后训练）。
- **高保真数据收集**：指尖 UMI + 动捕笼提供了亚毫米精度、第一人称、含力反馈的演示，填补了传统 UMI（SLAM）与遥操作之间的精度空白。
- **表示创新**：
  - delta-chunk 将策略学习与具体运动学解耦，支持零代码跨体部署。
  - 紧凑记忆编码器无新增参数，通过时间-空间分解高效聚合历史信息。
- **RL 后训练实用性强**：FlowPRO 无需奖励/价值模型，基于干预-回滚管道直接利用负样本，且近端正则化防止奖励黑客，可安全地与 SFT 数据共训。
- **部署优化**：异步推理 + 贝塞尔拼接保证高频闭环控制，无需额外学习模块。
