## 摘要
当前最广泛采用的机器人学习流程从机器人演示或结构化人类数据中学习技能，这些数据收集成本高昂且与特定具身绑定。相比之下，非结构化人类视频提供了一种可扩展的替代方案。它们包含跨物体、场景和策略的多样化操作演示，但并未直接与机器人动作相连。我们提出LUCID，一种两阶段框架，从互联网规模数据集的非结构化人类视频中学习任务意图，并在大规模并行仿真中学习机器人控制。意图模型从闭环中的当前观察预测短时意图（场景中接下来应该发生什么）。具身特定的感知运动策略将此意图转换为机器人动作。意图接口在控制器之间共享，因此同一意图模型可应用于不同具身，从我们的主灵巧手到平行爪夹持器。我们在五个真实世界操作任务上评估LUCID：仅由互联网视频监督的搅拌、擦拭和装箱，零样本迁移到新场景和新物体实例；以及各由1小时自收集手机视频监督的推T和电缆布线。项目页面：https://lucid-robot.github.io/。

## Abstract
The most widely-adopted robot learning pipelines today learn skills from robot demonstrations or structured human data, which are expensive to collect and tied to specific embodiments. In contrast, unstructured human videos provide a scalable alternative. They contain diverse manipulation demonstrations across objects, scenes, and strategies, but are not directly connected to robot action. We propose LUCID, a two-stage framework that learns task intent from unstructured human videos drawn from internet-scale datasets and learns robot control in massively-parallel simulation. The intent model predicts short-horizon intent (what should happen next in the scene) from the current observation in closed loop. An embodiment-specific sensorimotor policy converts this intent into robot actions. The intent interface is shared across controllers, so the same intent model can be applied to different embodiments, from our primary dexterous hand to a parallel-jaw gripper. We evaluate LUCID on five real-world manipulation tasks: stirring, wiping, and binning supervised by only internet video, with zero-shot transfer to novel scenes and object instances; and push-T and cable routing supervised by 1 hr each of self-collected smartphone video. Project page: https://lucid-robot.github.io/.

## 1. 核心问题与研究动机

- **背景**：当前机器人技能学习主要依赖两种数据源——机器人遥操作演示（昂贵、与特定本体绑定）或通过结构化设备（动捕、多视角、可穿戴）采集的人类演示（同样昂贵且需专用基础设施）。这两种方式规模化受限。
- **核心问题**：如何利用**海量、廉价但缺乏动作标注的非结构化人类视频**（如互联网视频）来学习本体无关的操作意图，并同时利用**大规模仿真**生成可扩展的动作标签，从而构建**无需遥操作、可跨本体泛化的灵巧操作技能**。
- **关键挑战**：非结构化视频只有观测，没有机器人动作；直接模仿轨迹或使用开环规划难以应对执行偏差。现有方法要么需要机器人数据微调，要么无法闭环恢复。

## 2. 方法论：核心思想与技术细节

### 2.1 整体架构（意图-控制分离）

LUCID 将操作任务拆解为两个独立模块：
- **意图模型** `fθ`：从当前观测预测短时物体流（object flow）+ 手掌姿态参考（palm-pose），**本体无关**，仅受人类视频监督。
- **传感器运动策略** `π`：将意图参考映射为具体机器人动作（关节命令），**本体特定**，通过仿真中的 RL 训练。

两者通过一个 **短时参考 R**（包含 T 步未来物体三维轨迹 + SE(3) 手掌姿态）通信，并在部署时**闭环运行**：意图模型不断从当前场景重新查询。

### 2.2 意图模型（Intent Model）

- **输入**：近期 RGB-D 帧堆叠 `I_t`、当前物体查询点 `x_trk_{n,0}`、当前手掌姿态 `(p_palm_0, R_palm_0)`
- **输出**：未来 T 步（1 秒）物体三维轨迹和手掌姿态轨迹
- **架构**：基于 CoTracker3 的点令牌 Transformer，做出三点改进：
  1. 使用冻结 DINOv3 编码 RGB，并通过残差适配器融合深度；
  2. 预测未来帧而非跟踪已观测帧；
  3. 添加一个手掌姿态令牌与 N 个物体令牌一起预测。
- **训练数据提取**：对每段人类视频窗口，依次使用 ViPE（深度/相机参数）、SAM 3.1（物体/人手掩码）、DenseTrack3Dv2（3D 轨迹）、WiLoR + 刚性拟合（手掌姿态），生成短时参考 R 作为监督。**人像像素被大量增强**以避免模型依赖人手外观。
- **损失函数**：物体流 MSE + 手掌位置 MSE + 手掌旋转 MSE，按未来步平均。

### 2.3 传感器运动策略（Sensorimotor Policy）

- **训练数据**：在 Isaac Lab 中程序化生成物体形状（组合基本体）和参考轨迹（分段：接近→手中运动→目标→脱离），每段随机采样抓取方式、路径和耦合模式，覆盖抓取、手中操作、放置、释放等。
- **动作空间**：输出 `[a_arm; a_eig; a_hnd]`：手臂关节位置增量、特征抓取系数（基于人类抓取重定向的主成分基）、每关节残差。通过 EMA 平滑与积分得到 PD 目标。
- **观测与目标**：
  - 教师 `π_T`：使用特权信息（完整表面采样点、关节速度、物体位姿等）。
  - 学生 `π_S`：使用外部 RGB-D 相机可见的表面采样点（限制在可见部分）+ 手腕深度图像 Dwrist。
- **网络架构**：基于 AME 交叉注意力架构，场景令牌来自物体轨迹点（点令牌化）和手腕深度图像（卷积令牌化），交叉注意力后接 MLP 躯干。
- **训练**：教师用 PPO 训练，配合自适应课程（重力、扰动、容差随能力提升）；学生通过混合目标蒸馏：PPO 损失 + 教师动作均值 MSE（权重 λ_D 从 1 退火到 0.1）。对手腕深度添加传感器噪声。
- **Sim-to-Real**：系统辨识关节动力学参数、匹配深度渲染噪声、随机化机器人基座/手腕相机偏移等。

### 2.4 部署流程

- 慢意图循环（1Hz）：SAM 刷新物体掩码 → 采样查询点 → 意图模型预测新参考 R。
- 快控制循环（50Hz）：策略根据当前点、参考 R、手腕深度、本体感知输出动作。
- 意图循环之间使用滑动窗口 3D 点跟踪器维持点的一致性。

## 6. 主要结论与发现

1. **闭环意图优于开环**：在三个 web 任务上，LUCID 平均成功率 73%，开环基线仅 28%。
2. **数据规模提升性能**：在装箱任务上，随着训练视频从 1k 增至 20k，实际成功率单调上升，持有集意图损失呈幂律下降。
3. **意图模型跨本体有效**：同一意图模型同时驱动灵巧手和平行爪，在推T和电缆布线任务上总成功率均为 63%（19/30），任务表现相当，电缆布线甚至更利于夹爪。
4. **传感器运动策略设计决策至关重要**：
   - 点令牌编码优于 MLP 拼接；
   - eigen-grasp 基能指导探索，加速训练；
   - 混合 PPO+蒸馏优于 DAgger-BC；
   - 手腕深度图像提供关键近场几何信息。

## 7. 优点

- **新颖的问题解耦**：首次将意图（“场景下一步应发生什么”）与控制（“如何用机器人实现”）彻底分离，使得两种独立可扩展的监督源（海量无标注视频 + 大规模仿真）能够有效融合。
- **闭环鲁棒性**：持续更新意图而非一次规划，使系统能从执行错误中恢复。
- **跨本体迁移**：仅需针对新本体重新训练仿真策略（通用训练配方），意图模型零成本复用。
- **弱监督能力**：仅需任务名称提示分割，无需动作标签、物体网格、动捕设备；且可涌现新行为（如擦拭后自动扔垃圾）。
- **系统集成深度**：将最先进的感知（SAM、ViPE、WiLoR）、追踪（DenseTrack3D）和 RL 训练技术有机整合，在真实机器人上验证了端到端性能。
- **开源与可复现**：提供项目页面、详细超参数表（附录 A/B），便于复现。

## 8. 不足与局限

1. **管道脆弱性**：系统过度模块化——SAM、DenseTrack3D、ViPE、WiLoR 每个都可能成为故障点，部署时感知问题（如手部遮挡、纹理缺失）会沿链传播导致失败。理想方案是端到端学习意图。
2. **任务-条件差距**：任务无明确终止条件时（如搅拌），模型会无限循环，需外部停止。新任务需手动筛选训练视频片段，难以扩展到数千任务。作者建议通过文本条件（像“搅拌”“放勺子”）解耦子任务。
3. **显式接口信息损失**：物体流+手掌姿态作为意图接口是手工设计的，丢失了手指配置、精细接触等信号，限制策略复现演示细节。作者建议使用潜在中间表示。
4. **仿真与真实差距仍存**：策略仅在刚性物体上训练，但实际成功操作了变形物体（纸巾、毛巾），说明泛化性；但未系统测试变形物体性能上界。
5. **实验多样性有限**：仅 5 个任务，未见更多复杂任务（如装配、多步骤组合），也未在更多异构本体（如双臂）上验证。
