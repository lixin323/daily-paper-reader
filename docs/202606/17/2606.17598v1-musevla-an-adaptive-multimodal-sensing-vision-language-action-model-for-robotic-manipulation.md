## 摘要
人类自然地利用多种感知模态与物理世界交互，而大多数用于机器人的视觉-语言-动作（VLA）模型仅依赖RGB观测。这限制了它们感知难以或无法从RGB相机推断的物理属性（如温度、声音或雷达响应）的能力。我们提出MuseVLA，一种适应性多模态感知VLA模型，将新型传感器作为按需工具集成到机器人操作中。给定任务指令和视觉上下文，MuseVLA首先生成传感器token和目标描述，选择要调用的感知模态以及关注对象，类似于带参数的工具调用。然后它将选定的传感器测量转换为接地传感器图像，这是一种统一的中间表示，编码异构读数以用于多模态融合和动作生成。这种设计将传感器特定处理与VLA主干解耦，实现了不同模态的高效集成。为减少对昂贵多传感器机器人数据集的需求，我们进一步引入数据合成流水线，用接地传感器图像增强现有RGB视频数据集，从而实现对未见传感器引导任务的泛化。我们在真实机器人上评估MuseVLA，执行需要多模态感知输入的挑战性灵巧手操作任务，包括温度引导的拾放、音频驱动的物体搜索和雷达辅助的隐藏物体检索。MuseVLA平均成功率达80.6%，显著优于仅RGB和多传感器VLA基线，并在未见任务上展现出强大的零样本能力。

## Abstract
Humans naturally leverage diverse sensing modalities to interact with the physical world, while most Vision-Language-Action (VLA) models for robotics rely solely on RGB observations. This limits their ability to perceive physical properties that are difficult or impossible to infer from RGB cameras, such as temperature, sound, or radar response. We present MuseVLA, an adaptive multimodal sensing VLA model that integrates novel sensors as on-demand tools for robotic manipulation. Given a task instruction and visual context, MuseVLA first generates a sensor token and target description that select the sensing modality to invoke and what to attend to, analogous to a tool call with arguments. It then converts the selected sensor measurement into a grounded sensor image, a unified intermediate representation that encodes heterogeneous readings for multimodal fusion and action generation. This design decouples sensor-specific processing from the VLA backbone, enabling efficient integration of diverse modalities. To reduce the need for expensive multisensory robot datasets, we further introduce a data synthesis pipeline that augments existing RGB video datasets with grounded sensor images, enabling generalization to unseen sensor-guided tasks. We evaluate MuseVLA on a real-world robot across challenging dexterous hand manipulation tasks that require multimodal sensing inputs, including temperature-guided pick-and-place, audio-driven object search, and radar-assisted hidden object retrieval. MuseVLA achieves 80.6% success rate on average, outperforming RGB-only and multisensory VLA baselines significantly, and exhibits strong zero-shot capabilities on unseen tasks.

## 2. 论文提出的方法论

### 核心思想
- 将传感器视为**可调用的工具**，依据任务指令和视觉场景，动态选择最相关的传感模态，并生成对应的“接地传感器图像”（Grounded Sensor Image）用于后续动作生成。
- 采用**解耦设计**：传感器特定处理与 VLA 主干分离，通过统一中间表示（接地传感器图像）实现异构模态的即插即用。

### 关键技术细节
1. **三级流程**：
   - **阶段1（传感器选择 & 目标描述生成）**：VLM 根据语言指令 `l` 和 RGB 观测 `o_t` 生成传感器 token `l_s`（如 `<thermal>`）和目标描述 `l_d`（如 “bottles”）。
   - **阶段2（接地传感器图像构建）**：调用选中的传感器获得测量 `s_{i,t}`，利用分割模型（SAM3）根据 `l_d` 生成目标区域二值掩码 `M`，将传感器热图 `s` 与 RGB 图像按掩码叠加：`m = M ⊙ s + (1 − M) ⊙ o_RGB`。
   - **阶段3（动作生成）**：将接地传感器图像 `m` 作为额外视觉输入，与原始 RGB、语言特征一起送入动作专家（扩散 Transformer）生成动作序列。

2. **自适应传感器选择**：引入可学习传感器 token（`<None>`, `<thermal>`, `<acoustic>`, `<mmWave>`），作为离散语言 token 由 VLM 预测，实现任务条件化选择。

3. **数据合成管道**：
   - 从现有 RGB 机器人数据集中，通过注入物理属性关键词（如 “hot”、“ringing”）并覆盖颜色掩码，模拟传感器热图。
   - 构建传感器字典（如 thermal → “hot/cold/warm”），随机选取模态和关键词，调用 GPT-5.2 生成目标描述，SAM3 分割后叠加颜色。
   - 合成数据涵盖 9.6K 回合、105万帧，覆盖 1000+ 物体，用于预训练增强零样本泛化。

4. **训练损失**：
   - VLM 损失：交叉熵损失 `L_VLM = L_sensor + L_target`（传感器 token + 目标描述）。
   - VLA 损失：扩散模型 MSE 损失。

1. **MuseVLA 显著优于 RGB-only 和原始多传感器基线**：在训练任务上平均成功率 76.4%（仅真实数据）和 80.6%（+预训练），远超 π0-RGB（20.8%）和 π0-Raw（27.8%）。

## 7. 优点

- **创新性**：首次将传感器作为可调用的“工具”融入 VLA，实现了任务驱动的自适应多模态感知，更贴近人类行为模式。
- **框架通用性**：接地传感器图像将所有传感器读数统一到 RGB 空间，无需专用编码器，新传感器可即插即用。
- **数据高效性**：设计数据合成流水线，从现有 RGB 数据生成多感官数据，缓解真实多传感器数据稀缺问题，降低了采集成本。
- **实验全面性**：不仅评估单模态任务，还设计了多阶段链式任务和零样本未见任务，验证了模型的泛化能力和自适应调度能力。
- **开源承诺**：将开源数据和代码，促进社区研究。

## 8. 不足与局限

- **真实数据规模较小**：仅 720 个演示回合，限制了复杂场景下的鲁棒性；后续可收集更大量多样数据。
- **依赖外部分割模块**：使用 SAM3 进行目标分割，如果 SAM3 失败则影响整个接地图像质量；且分割模块未与 VLA 联合优化。
- **声学任务成功率偏低**（58.3%），主要因为抓取软织物（衣服、毛巾）的灵巧手操纵困难，非模型感知瓶颈。
- **零样本未见任务仍有提升空间**（66.7% vs 训练任务 80.6%），特别是声学模态（56.3%），提示合成数据可能未充分覆盖声学控制任务的多样性。
- **传感器空间对齐依赖固定单应性变换**，适用于桌面操作距离，但在更远或更复杂 3D 空间中可能存在误差。
- **未探索更丰富传感器（如力触觉、嗅觉）**，论文只验证了热、声、雷达三种，框架设计虽可扩展但缺乏实证。
- **未见对比最新多感官 VLA 模型**（如 OmniVLA、MLA 等），现有基线主要为 π0 变体，可能遗漏更强基线。
