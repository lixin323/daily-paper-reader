## 摘要
世界模型正从被动的视觉生成器转变为物理人工智能的基础性、可操作基础设施：它们必须原生地从异构经验中获取世界知识，在长时间跨度上维持持久状态，并在实际部署限制下高效执行。我们提出Kairos，一个围绕这些要求设计的原生世界模型栈。（1）Kairos通过首创由跨具身数据课程引导的原生预训练范式来学习世界，该范式将开放世界视频、人类行为数据和机器人交互组织成渐进式发展路径。（2）Kairos通过在配备混合线性时序注意力的原生统一架构中统一世界理解、生成和预测来维护世界，其中滑动窗口注意力捕捉局部动态，扩张滑动窗口捕捉中程依赖关系，门控线性注意力维持持久全局记忆。我们建立了形式化理论界限，证明这种时间分解严格限制了误差累积，在数学上保证了跨扩展时间跨度的状态传播。（3）Kairos通过纳入部署感知系统协同设计来运行世界，支持在服务器和消费级硬件上为现实世界的观测-行动-反馈循环生成低延迟的推演。在具身世界模型、长时域和行动策略基准上的实验表明，Kairos在实现顶级性能的同时提供了强大的效率-能力权衡。这些结果共同将Kairos定位为未来自进化物理智能的凝聚性操作基础。

## Abstract
World models are transitioning from passive visual generators to foundational, operational infrastructure for Physical AI: they must natively acquire world knowledge from heterogeneous experience, maintain persistent states over long horizons, and execute efficiently within real deployment constraints. We introduce Kairos, a native world model stack designed around these requirements. (1) Kairos learns the world by pioneering a Native Pre-training Paradigm governed by a Cross-Embodiment Data Curriculum, which organizes open-world videos, human behavioral data, and robot interactions into a progressive developmental pathway. (2) Kairos maintains the world by unified world understanding, generation, and prediction within a Native Unified Architecture equipped with Hybrid Linear Temporal Attention, where sliding-window attention captures local dynamics, dilated sliding windows capture mid-range dependencies, and gated linear attention maintains persistent global memory. We establish formal theoretical bounds demonstrating that this temporal factorization strictly limits error accumulation, mathematically guaranteeing state propagation across extended horizons. (3) Kairos runs the world by incorporating a Deployment-Aware System Co-Design to support low-latency rollout generation on server and consumer-grade hardware for real-world observation-action-feedback loops. Experiments on embodied world-model, long-horizon, and action-policy benchmarks show that Kairos achieves top level performance while offering a strong efficiency-capability trade-off. Together, these results position Kairos as a cohesive operational foundation for future self-evolving physical intelligence.

- **核心问题**：物理 AI（Physical AI）需要世界模型从被动的视觉生成器转变为原生的、可部署的操作基础设施。但现有世界模型面临四大瓶颈：
  1. **学习碎片化**：知识来源（开放世界视频、人类行为数据、机器人交互数据）异构且不匹配，难以统一获取世界知识。
  2. **长时域记忆缺失**：局部时序平滑方法无法保证长期状态一致性（如物体持久性、延迟物理效应），数学上存在不可消除的误差累积。

  4. **部署效率低下**：即使模型性能强，若推理延迟高、内存占用大，则无法嵌入实时观测-行动-反馈闭环，阻碍在线自进化。

- **整体含义**：该论文主张世界模型必须同时解决“学习世界”、“维持世界状态”和“运行世界”三个层面，而非仅作为视频生成展示。Kairos 旨在构建一个原生的、可部署的世界模型栈，为未来自进化的物理智能奠定操作基础。

## 2. 方法论：核心思想与关键技术细节

### 核心思想：三支柱自进化框架
- **学习世界**：Cross-Embodiment Data Curriculum (CEDC) —— 原生预训练范式
- **维持世界**：Native Unified Architecture with Hybrid Linear Temporal Attention —— 统一理解-生成-预测
- **运行世界**：Deployment-Aware System Co-Design —— 低延迟、低内存推理

### 关键技术细节

#### （1）Cross-Embodiment Data Curriculum (CEDC)
- **阶段 I：物理知识注入**。使用海量开放世界视频（数百万小时），学习通用物理规律（重力、碰撞、流体等），通过 Chain-of-Thought 文本增强物理推理。
- **阶段 II：人类行为对齐**。使用超 10 万小时人类中心数据（第一/三人称），学习结构化任务语义和因果关系。
- **阶段 III：机器人动作接地**。使用机器人交互数据（如 AgiBotWorld-Beta, Droid），将物理和行为先验锚定到具体具身控制空间。
- **训练流程**：三个阶段对应三阶段预训练：Stage I 仅训练 Video DiT（视频扩散 Transformer），Stage II 继续优化 Video DiT，Stage III 联合训练 Video DiT 和 Action DiT，损失函数为 `L = L_video + λ L_action`，采用 Flow Matching 目标。

#### （2）Native Unified Architecture with Hybrid Linear Temporal Attention
- **三大模块**：World Understanding（VLM，如 Qwen 系列）、World Generation（扩散 DiT）、World Prediction（行动 DiT）。
- **混合线性注意力机制**：由多个混合块组成，每个块依次包含：
  - **Sliding Window Attention (SWA)**：局部短程动态，窗口大小覆盖相邻几帧。
  - **Dilated Sliding Window Attention (DSWA)**：中程依赖，使用扩张因子（如 6, 12）沿时间轴扩展视野。
  - **Gated Linear Attention (GLA)**：全局因果记忆，基于 GatedDeltaNet（门控 delta 更新规则），具有线性复杂度且可证明具备收缩性，误差不累积。
- **理论分析**：定理 1 证明纯局部窗口必然产生不可消除的预测风险；定理 2 证明该混合分解可逼近最优预测，且误差由分支近似质量和全局记忆的几何衰减共同控制。

#### （3）Deployment-Aware System Co-Design
- **时间步蒸馏**：使用 Distribution Matching Distillation 和 Consistency Distillation，将 480P 教师模型蒸馏为仅 4 步采样的学生模型。
- **硬件感知优化**：混合并行推理（Ulysses + Tensor Parallel）、DiT-Cache 优化、FP8 低精度、INT4 权重量化、Tiled Gated DeltaNet 流式访问等。
- **结果**：在 Nvidia A800 上 480P 视频生成达到实时（~11.7s/5s 视频）；相比 Wan2.2-5B 等基线加速 2.5-85 倍。
