## 摘要
现代视觉-语言-动作（VLA）模型通常难以泛化到新的设置，例如改变的相机视角或机器人形态，因为它们通常仅基于当前观测和语言指令进行条件化。由于忽略了底层系统配置作为一个变量，这些模型隐式地假设了训练中遇到的固定执行上下文，从而需要对任何新环境进行数据密集型的微调。在这项工作中，我们引入了上下文世界建模（ICWM），这是一个将系统识别视为上下文自适应问题的框架。ICWM使机器人策略能够从自生成的、任务无关的简短交互历史中自主推断出关键的系统变量。与传统的利用演示来指定执行什么任务的上下文学习不同，ICWM利用上下文窗口来理解系统如何运行。通过在任务执行前处理这些交互，模型隐式地捕获了当前系统的世界动态，从而无需参数更新即可适应新的配置。在仿真和真实世界机器人平台上的大量实验表明，ICWM在新型相机视角下显著优于标准VLA基线。

## Abstract
Modern Vision-Language-Action (VLA) models often fail to generalize to novel setups, such as altered camera viewpoints or robot morphologies, because they are typically conditioned only on current observations and language instructions. By ignoring the underlying system configuration as a variable, these models implicitly assume a fixed execution context encountered during training, necessitating data-intensive fine-tuning for any new environment. In this work, we introduce In-Context World Modeling (ICWM), a framework that treats system identification as an in-context adaptation problem. ICWM enables robot policies to autonomously infer essential system variables from a short history of self-generated, task-agnostic interactions. Unlike traditional In-Context Learning that uses demonstrations to specify what task to perform, ICWM leverages the context window to understand how the system operates. By processing these interactions before task execution, the model implicitly captures the world dynamics of the current system, enabling adaptation to novel configurations without parameter updates. Extensive experiments in simulation and on real-world robot platforms demonstrate that ICWM significantly outperforms standard VLA baselines on novel camera viewpoints.

## 1. 核心问题与整体含义（研究动机和背景）

当前主流视觉-语言-动作（VLA）模型（如RT-2、OpenVLA、π0等）仅以当前观测和语言指令为条件生成动作，隐式假设训练时遇到的系统配置（如相机视角、机器人形态）是固定的。当部署环境出现变化（如新视角、不同机器人结构）时，模型无法自动校准动作-观测映射关系，导致性能严重下降。现有解决方案多依赖于特定场景的微调（需要大量人工干预）或提供任务演示的上下文学习（仍需要人类标注）。作者将这一失效问题重新定义为**测试时系统识别问题**：策略在测试时缺乏对当前系统配置ψ的知识。受人类操作新设备时通过随机探索建立心智模型的启发，本文提出了**上下文世界建模（ICWM）**，使机器人能够通过自生成的、任务无关的短交互历史隐式推断系统动态，实现无需参数更新的零样本自适应。

## 2. 方法论

核心思想：将VLA策略从静态映射转化为自适应的推理引擎——通过上下文窗口传递系统识别信息（“系统如何运行”），而非指定具体任务行为（“做什么”）。

关键技术细节：
- **形式化定义：** 系统配置ψ是时间不变的隐变量，包含相机视角、运动学参数等。标准VLA策略πθ(at|ot,l)忽略ψ，隐式假设ψ固定。理想策略应为π*θ(at|ot,l,ψ)。ICWM通过自生成交互历史T = {(o_si, a_i, o_ei)}来隐式估计ψ，即πθ(at|Ψ(T), ot,l)，其中Ψ是共享骨干网的计算过程。
- **训练阶段：** 每个训练样本由N个任务无关的交互片段（从同一配置下的随机探索轨迹中采样）作为前缀，后接任务观测和指令。模型需从上下文T中提取动态信息以正确预测动作，从而学习隐式世界建模。损失函数为负对数似然。
- **推理阶段：** 分为主动探测和上下文执行两步。①主动探测：机器人执行N步随机的末端执行器运动（在安全工作区内，不干扰任务物体），记录每步的(开始图像，动作，结束图像)三元组。②上下文执行：将N个三元组拼接到任务查询之前，通过单次前向传播生成动作。整个过程无需梯度更新、无需任务演示、无需预先标定。
- **特点：** 共享VLA骨干参数，无额外参数；探测动作是任务无关的（随机，不携带任务信息），但通过视觉-运动联合序列隐式暴露了当前配置的因果结构。

**对比方法：**
- **控制对比：** ①多视图行为克隆（MV，无上下文）；②显式配置（EXP，给定真实相机角度为文本输入）。

## 6. 主要结论与发现

1. **ICWM显著提升OOD视角泛化：** 在LIBERO上，ICWM的OOD平均成功率比MV高13.0%（25.0% vs 22.0%）；真实机器人上提高71%（17%→29%），在举升任务中改进达175%。
2. **隐式系统识别优于显式指定：** 即使提供真实相机角度（EXP），其OOD性能仍低于ICWM（差9.5%），说明交互上下文不仅提供视角信息，还蕴含完整动作-观测对应关系。
3. **长时任务收益最大：** LIBERO-Long上ICWM比MV高26.3%（OOD），因长时任务放大小空间误差，ICWM通过持续上下文校正缓解级联错误。
4. **上下文必须对齐：** 提供错误上下文（视角偏移180°）导致性能低于无上下文（18.9% vs 22.0%），说明模型是真实利用了上下文进行系统辨识，而非忽略。
5. **随机探测足够有效：** 所有探测策略（随机、水平、垂直、旋转）均一致优于MV，且不同策略结果相近，说明收益来自交互格式本身而非特定运动模式。
6. **泛化超越视角变化：** ICWM也优于MV于语义场景变化（干扰物+7.5%，纹理+3.7%）和形态变化（UR5e垫片+60%，WindowX连杆偏移10-20%时+20-34%）。

## 7. 优点

- **新颖的问题视角：** 将VLA泛化失效重新定义为系统识别问题，并类比人类探索行为，动机直观且有力。
- **参数高效且实用：** 零参数更新、零任务演示、零先验标定；探测动作可自动生成，一次执行后复用KV缓存可降延迟。
- **隐式世界建模：** 无需单独的世界模型骨干和专用训练损失，通过共享骨干和上下文自动涌现系统辨识能力。
- **广泛验证：** 在仿真（LIBERO）和真实机器人（UR5e、WindowX）上，从视角、语义、形态三个维度系统性地证明了泛化能力，消融实验严密。
- **分析深入：** 通过t-SNE可视化隐式空间聚类、错误上下文负迁移、不同探测策略对比等，实证了机制的有效性。

## 8. 不足与局限

- **部分视角仍困难：** 在OOD视角135°上所有方法（包括ICWM）性能极低（LIBERO上<3%），说明存在视角特定的感知瓶颈（如遮挡、视野受限），ICWM无法完全克服。
- **探测阶段需短暂执行：** 虽然比预先标定更实用，但仍需机器人执行约5-6秒的随机运动，且需确保不碰撞物体，可能不适用于高动态环境或禁止运动前的场景。
- **未测试零样本到全新任务或物体：** 当前实验均在训练任务上评估新视角/形态，未评估语义任务迁移（如训练叠杯测试拾取）。未来可拓展到任务级泛化。
- **算力依赖：** 尽管推理可通过KV缓存优化，但初始上下文前向传播仍需一次处理2N图像+N动作token，对边缘设备有一定负担。
- **对比方法局限性：** 上下文参考基线（NORA、π-FAST、π0.5）是在单视角下微调的，无法代表公平的零样本对比（它们没有多视角训练数据）。控制对比MV和EXP的设计是公平的，但缺少其他在线自适应方法（如梯度元学习）的直接比较。
- **理论证明较弱：** 命题1仅证明了交互上下文比单图像信息更多，但未推导信息增益与特定探测策略的上下界关系，也未给出Ψ(T)的显式形式。
